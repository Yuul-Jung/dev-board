# Arduino 트랙 검토 (2026-10-31)

<!-- nav -->[저장소 홈](../README.md) › [arduino](README.md)

`arduino/` 의 01~16차시 실습(문서·스케치)을 `devices/` 의 확인된 값과 대조한 결과입니다. 프로젝트 문서와의 전체 대조는 [../devices/REVIEW-20261031.md](../devices/REVIEW-20261031.md).

## 1. 고친 것
- **구조**: 02~08차시와 01차시 README 가 저장소 루트 `examples/` 에 잘못 놓여 있어 [README](README.md) 링크 8개와 01차시 내부 링크가 깨져 있었음 → `arduino/examples/` 로 이동(내용 변경 없음). 01차시는 README 와 .ino 가 서로 다른 폴더에 있었음.
- **문장**: 09~16차시 개요의 조사 오류(「타이머을」「거리을」「경고을」 등 7곳) 수정.
- **14차시 스케치**: 규격 범위(2~400 cm) 밖 값을 그대로 출력하던 것을 `OUT OF RANGE` 로 처리.
- **16차시 스케치**: `requestTemperatures()` 가 750 ms 까지 기다려 거리 경고가 약 1.8 s 마다만 갱신되던 것을 비차단(millis)으로 변경, 범위 밖 거리는 경고에서 제외.
- 14·16 스케치는 **스텁 헤더로 문법만 확인**했고 Arduino IDE·라이브러리 컴파일, 보드 실행은 하지 않았습니다(미확인).

## 2. 고치지 않고 남긴 것 (미결·미확인)
- 10차시: 3음 멜로디로 코드·README를 수정해 ROADMAP과 교육 범위를 일치시킴. 코드 변경 뒤 Arduino IDE 컴파일·실물 시험은 아직 하지 않음.
- 13차시: PIR 예열 시간·OUT 3.3 V 가 UNO R4(5 V 로직) 입력 High 로 인식되는지 — 둘 다 근거 자료 없음(미확인).
- 15차시: Adafruit DHT 라이브러리의 UNO R4 호환 미확인.
- 01~16차시 전체: 컴파일·실물 시험 미실시(각 README 의 검증 상태와 같음). 이 검토도 그 상태를 바꾸지 않음.

## 최신 추가 검토 (2026-10-31)
- 10차시: 기존 단일 440 Hz 예제를 440→523→659 Hz 세 음의 비차단 반복으로 확장. 버튼 해제 시 `noTone()`을 호출한다. 부품은 능동 부저가 아니라 수동 피에조 부저를 사용한다.
- `examples/`(저장소 루트)에 과거 01차시 자료가 남아 있고, 정식 Arduino 전용 교육자료는 `arduino/examples/`이다. 삭제하지 않고 레거시 여부를 확인해야 한다.
- `arduino/index.html` 및 각 실습의 `index.html`은 자동 생성 이동 페이지이므로 본문 교재처럼 표시하면 안 된다. 생성기 개선은 별도 작업으로 관리한다.
- 검증 단계: 작성 → Arduino IDE 컴파일 → 배선/전압 검증 → 실물 실행. 각 검증을 증거 없이 올리지 않는다.

## 3. 번호 혼동 주의
Arduino 32차시([ROADMAP](ROADMAP.md))와 프로젝트 문서의 32차시(FPGA/SoC 트랙, [SESSION-MAP](../devices/SESSION-MAP.md))는 **서로 다른 교육과정**입니다. 예: 09차시는 Arduino 쪽은 millis 타이머, SoC 쪽은 서보. 번호만으로 부르지 말고 트랙을 함께 적으십시오.
