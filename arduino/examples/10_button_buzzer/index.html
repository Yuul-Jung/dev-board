10차시 — 버튼과 수동 부저

Arduino 목차 · 32차시 테크트리

GitHub 에서 이 폴더 보기 · README

Arduino 목차 · 32차시 테크트리

개요

능동 부저와 수동 피에조 부저의 차이를 구분하고, 버튼을 누르는 동안 세 음이 반복되는 멜로디를 구현한다. 기본 예제에서 확인한 입력·출력 개념을 이어서 사용한다.

준비 및 배선

  • 보드: Arduino UNO R4 Minima 또는 WiFi. 실제 보드에 맞게 Arduino IDE 보드와 포트를 선택한다.
  • 배선: D2 버튼-GND, D9 수동 피에조 부저 신호, 부저 GND 공통
  • 주의: 수동 피에조(소전류) 부저. 능동 부저는 tone 출력 목적에 맞지 않습니다.

전체 코드

10_button_buzzer.ino — 이 폴더의 스케치 원본

실행 절차

  • Arduino IDE에서 10_button_buzzer.ino를 열고 보드·포트를 선택한다.
  • 필요한 라이브러리를 설치하고 스케치를 검증(컴파일)한 뒤 업로드한다.
  • 배선을 확인하고 입력을 변화시키면서 출력 반응을 관찰한다.
  • Serial 출력이 있는 차시는 115200 baud로 시리얼 모니터를 연다.

예상 결과

버튼을 누르면 440Hz → 523Hz → 659Hz가 약 250ms 간격으로 반복되며, 놓으면 즉시 멈춥니다.

검증 상태

  • 코드 작성: 완료
  • Arduino IDE 컴파일: 미실행
  • UNO R4 실물 시험: 미실행
  • 실제 모듈별 전압·핀 배치 대조: 시험 전 확인 필요

능동 부저와 수동 부저

  • 능동 부저: 자체 발진 회로가 있으므로 전원 또는 제어 신호로 켜고 끄는 데 적합하며, 임의 음계 재생에는 적합하지 않습니다.
  • 수동 피에조 부저: 외부 주파수 신호가 필요하므로 tone()으로 음계를 구현합니다. 반드시 부품의 전압·전류 정격을 확인합니다.

개정 메모

  • (변경) 32차시 ROADMAP과 일치하도록 3음 멜로디를 추가했습니다. millis() 간격으로 다음 음을 선택하며 delay() 없이 버튼 해제를 검사합니다.
  • (참고) 실제 음량, 주파수 정확도, UNO R4 실물 동작은 아직 검증하지 않았습니다.

공통 모듈 자료: devices (해당 자료의 RTL/C 코드는 Arduino 스케치가 아님).

전체 스케치 — 10_button_buzzer.ino

// 10차시: 수동 피에조 부저에서 버튼을 누르는 동안 3음 멜로디 반복
// 버튼 D2-GND, 수동 피에조 부저 D9-GND (구동 전류 확인)
// 능동 부저는 자체 발진하므로 이 멜로디 실습에 사용하지 않는다.
const byte BTN=2, BUZZER=9;
const unsigned int notes[]={440, 523, 659}; // A4, C5, E5
const unsigned long NOTE_MS=250;
bool playing=false;
byte noteIndex=0;
unsigned long noteAt=0;

void setup() {
  pinMode(BTN, INPUT_PULLUP);
}

void loop() {
  const unsigned long now=millis();
  const bool pressed=(digitalRead(BTN)==LOW);
  if (!pressed) {
    if (playing) noTone(BUZZER);
    playing=false;
    noteIndex=0;
    return;
  }
  if (!playing) {
    playing=true;
    noteAt=now;
    noteIndex=0;
    tone(BUZZER, notes[noteIndex]);
  } else if (now-noteAt>=NOTE_MS) {
    noteAt=now;
    noteIndex=(noteIndex+1)%3;
    tone(BUZZER, notes[noteIndex]);
  }
}
