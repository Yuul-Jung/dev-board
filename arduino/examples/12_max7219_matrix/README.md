# 12차시 — MAX7219 LED 매트릭스

[Arduino 목차](../../README.md) · [32차시 테크트리](../../ROADMAP.md)

## 개요
MAX7219 LED 매트릭스을 Arduino UNO R4의 입출력으로 구현한다. 기본 예제에서 확인한 입력·출력 개념을 이어서 사용한다.

## 준비 및 배선
- 보드: Arduino UNO R4 Minima 또는 WiFi. 실제 보드에 맞게 Arduino IDE 보드와 포트를 선택한다.
- 배선: MAX7219 8×8 모듈 VCC→5V, GND 공통, DIN→D11, CLK→D13, CS→D10. 모듈의 전원·논리 레벨 사양을 확인합니다.
- 주의: SPI 비트 전송은 직접 작성한 간단한 예제입니다. LED 행·열 방향은 모듈마다 다를 수 있습니다.

## 전체 코드
[12_max7219_matrix.ino](12_max7219_matrix.ino) — 이 폴더의 스케치 원본

## 실행 절차
1. Arduino IDE에서 `12_max7219_matrix.ino`를 열고 보드·포트를 선택한다.
2. 필요한 라이브러리를 설치하고 스케치를 검증(컴파일)한 뒤 업로드한다.
3. 배선을 확인하고 입력을 변화시키면서 출력 반응을 관찰한다.
4. Serial 출력이 있는 차시는 115200 baud로 시리얼 모니터를 연다.

## 예상 결과
8×8 매트릭스에서 대각선 패턴과 반대 대각선 패턴이 교대로 표시됩니다.
