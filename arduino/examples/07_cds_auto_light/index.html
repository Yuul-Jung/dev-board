07차시 — CdS 자동 조명

Arduino 전체 목차 · 32차시 테크트리

개요

입력 신호를 읽고 출력 장치를 제어한다. 이전 차시와 비교하여 늘어난 입출력 기능을 확인한다.

준비

  • 대상 보드: Arduino UNO R4 Minima 또는 WiFi. 사용 보드와 포트는 Arduino IDE에서 직접 선택한다.
  • CdS·10kΩ 저항·LED·220Ω 저항·점퍼선
  • 부품·모듈 회로도를 확인하고 외부 전원과 GND를 연결한다. LED에는 전류 제한 저항을 넣는다.

배선

5V → CdS → A0 → 10kΩ → GND; D9 → 220Ω → LED 양극, LED 음극 → GND

전체 소스

07_cds_auto_light.ino

소스 파일은 이 폴더에서 열어 그대로 업로드한다. (README와 .ino를 같은 디렉터리에 배치함)

실행 절차

  • Arduino IDE에서 보드와 USB 포트를 선택한다.
  • 스케치 파일을 열어 컴파일(검증)하고 업로드한다.
  • 입력값을 변화시키면서 출력의 변화를 관찰한다.

예상 결과

어두울수록 LED가 밝아진다. 센서·조명 간섭이 있으면 위치를 분리한다.

확인 및 주의

  • 상태: 소스 작성 / 컴파일 미검증 / 실물 미검증
  • 실제 컴파일 성공 또는 보드 동작을 아직 주장하지 않는다.
  • CdS는 조도(lux)를 직접 측정하지 않는다. 분압 저항과 주변 빛에 따라 제어 범위가 달라진다.
  • 공통 부품 자료: devices/

전체 스케치 — 07_cds_auto_light.ino

// 밝을수록 A0 증가하는 분압 배치: 출력은 어두울수록 증가
const byte PWM_LED=9;
void setup() { pinMode(PWM_LED,OUTPUT); analogReadResolution(10); analogWriteResolution(8); }
void loop() {
  int light=analogRead(A0);
  int duty=map(constrain(light,0,1023),0,1023,255,0);
  analogWrite(PWM_LED,duty);
  delay(30);
}
