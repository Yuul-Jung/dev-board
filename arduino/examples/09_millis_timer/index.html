개요

millis 비차단 타이머를 Arduino UNO R4의 입출력으로 구현한다. 기본 예제에서 확인한 입력·출력 개념을 이어서 사용한다.

준비 및 배선

  • 보드: Arduino UNO R4 Minima 또는 WiFi. 실제 보드에 맞게 Arduino IDE 보드와 포트를 선택한다.
  • 배선: D2 버튼-GND, 내장 LED
  • 주의: GPIO 시간 제어

전체 코드

09_millis_timer.ino — 이 폴더의 스케치 원본

실행 절차

  • Arduino IDE에서 09_millis_timer.ino를 열고 보드·포트를 선택한다.
  • 필요한 라이브러리를 설치하고 스케치를 검증(컴파일)한 뒤 업로드한다.
  • 배선을 확인하고 입력을 변화시키면서 출력 반응을 관찰한다.
  • Serial 출력이 있는 차시는 115200 baud로 시리얼 모니터를 연다.

예상 결과

버튼을 누를 때마다 점멸 활성화가 전환되고 활성화 중 약 500ms마다 LED가 토글됩니다.

검증 상태

  • 코드 작성: 완료
  • Arduino IDE 컴파일: 미실행
  • UNO R4 실물 시험: 미실행
  • 실제 모듈별 전압·핀 배치 대조: 시험 전 확인 필요

공통 모듈 자료: devices (해당 자료의 RTL/C 코드는 Arduino 스케치가 아님).

전체 스케치 — 09_millis_timer.ino

const byte BTN=2;
bool lastRead=HIGH, stable=HIGH, enabled=false, led=false;
unsigned long edgeTime=0, tickTime=0;
void setup() {
  pinMode(BTN,INPUT_PULLUP);
  pinMode(LED_BUILTIN,OUTPUT);
}
void loop() {
  unsigned long now=millis();
  bool raw=digitalRead(BTN);
  if (raw!=lastRead) edgeTime=now;
  if (now-edgeTime>=30 && raw!=stable) {
    stable=raw;
    if (stable==LOW) {
      enabled=!enabled;
      tickTime=now;
      led=false;
      digitalWrite(LED_BUILTIN,LOW);
    }
  }
  lastRead=raw;
  if (enabled && now-tickTime>=500) {
    tickTime=now;
    led=!led;
    digitalWrite(LED_BUILTIN,led?HIGH:LOW);
  }
}
