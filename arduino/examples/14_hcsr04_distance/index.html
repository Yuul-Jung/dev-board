개요

HC-SR04 초음파 거리를 Arduino UNO R4의 입출력으로 구현한다. 기본 예제에서 확인한 입력·출력 개념을 이어서 사용한다.

준비 및 배선

  • 보드: Arduino UNO R4 Minima 또는 WiFi. 실제 보드에 맞게 Arduino IDE 보드와 포트를 선택한다.
  • 배선: HC-SR04 VCC→5V, GND 공통, TRIG→D7, ECHO→D8(UNO R4 입력 규격 및 실제 센서 모듈 확인).
  • 주의: pulseIn은 최대 30ms 동안 블로킹될 수 있으므로 비차단 구조로 확장할 때 별도 상태 기계가 필요합니다.

전체 코드

14_hcsr04_distance.ino — 이 폴더의 스케치 원본

실행 절차

  • Arduino IDE에서 14_hcsr04_distance.ino를 열고 보드·포트를 선택한다.
  • 필요한 라이브러리를 설치하고 스케치를 검증(컴파일)한 뒤 업로드한다.
  • 배선을 확인하고 입력을 변화시키면서 출력 반응을 관찰한다.
  • Serial 출력이 있는 차시는 115200 baud로 시리얼 모니터를 연다.

예상 결과

물체를 움직이면 센티미터 거리 값이 시리얼 모니터에 출력됩니다. 무응답은 TIMEOUT으로 표시됩니다.

검증 상태

  • 코드 작성: 완료
  • Arduino IDE 컴파일: 미실행
  • UNO R4 실물 시험: 미실행
  • 실제 모듈별 전압·핀 배치 대조: 시험 전 확인 필요

개정 메모 (2026-10-31 검토)

  • 스케치에 2~400 cm 범위 검사를 추가했습니다(범위 밖은 OUT OF RANGE). 근거: HC-SR04 문서의 데이터시트 범위. pulseIn 제한(30 ms ≈ 5 m)은 규격 범위보다 넓어서 범위 밖 값이 그대로 출력되던 문제입니다.
  • 환산은 µs×0.0343/2(≈µs/58.3)이며 데이터시트 식 µs/58 과 약 0.5 % 차이입니다(계산).
  • 개정한 스케치는 스텁 헤더로 문법만 확인했고 Arduino IDE 컴파일·보드 실행은 하지 않았습니다.

공통 모듈 자료: devices (해당 자료의 RTL/C 코드는 Arduino 스케치가 아님).

전체 스케치 — 14_hcsr04_distance.ino

// HC-SR04: cm = 에코 폭(µs)/58 근처(데이터시트 식은 devices/gpio/hc-sr04.md). 규격 범위 2~400 cm 밖은 신뢰하지 않는다.
const byte TRIG=7,ECHO=8;
void setup() {
  pinMode(TRIG,OUTPUT); pinMode(ECHO,INPUT);
  digitalWrite(TRIG,LOW);
  Serial.begin(115200);
}
void loop() {
  digitalWrite(TRIG,LOW); delayMicroseconds(2);
  digitalWrite(TRIG,HIGH); delayMicroseconds(10);
  digitalWrite(TRIG,LOW);
  unsigned long us=pulseIn(ECHO,HIGH,30000UL);
  if (us==0) Serial.println("TIMEOUT");
  else {
    float cm=(us*0.0343f)/2.0f;
    if (cm<2.0f || cm>400.0f) Serial.println("OUT OF RANGE");
    else { Serial.print("Distance cm: "); Serial.println(cm,1); }
  }
  delay(100); // 측정 주기 60 ms 초과 권장
}
