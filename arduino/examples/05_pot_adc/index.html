05차시 — 가변저항 ADC

Arduino 전체 목차 · 32차시 테크트리

GitHub 에서 이 폴더 보기 · README

Arduino 전체 목차 · 32차시 테크트리

개요

입력 신호를 읽고 출력 장치를 제어한다. 이전 차시와 비교하여 늘어난 입출력 기능을 확인한다.

준비

  • 대상 보드: Arduino UNO R4 Minima 또는 WiFi. 사용 보드와 포트는 Arduino IDE에서 직접 선택한다.
  • 10kΩ 가변저항·점퍼선
  • 부품·모듈 회로도를 확인하고 외부 전원과 GND를 연결한다. LED에는 전류 제한 저항을 넣는다.

배선

5V ↔ 가변저항 바깥 단자, GND ↔ 반대 바깥 단자, A0 ↔ 가운데 와이퍼

전체 소스

05_pot_adc.ino

소스 파일은 이 폴더에서 열어 그대로 업로드한다. (README와 .ino를 같은 디렉터리에 배치함)

실행 절차

  • Arduino IDE에서 보드와 USB 포트를 선택한다.
  • 스케치 파일을 열어 컴파일(검증)하고 업로드한다.
  • 시리얼 모니터를 115200 baud로 열어 가변저항을 회전해 출력값을 관찰한다.

예상 결과

시리얼 모니터에 ADC 원시값과 전압 추정값이 출력된다.

확인 및 주의

  • 상태: 소스 작성 / 컴파일 미검증 / 실물 미검증
  • 실제 컴파일 성공 또는 보드 동작을 아직 주장하지 않는다.
  • 모듈의 전원 정격과 실제 배선을 확인한 후 전원을 넣는다.
  • 공통 부품 자료: devices/

전체 스케치 — 05_pot_adc.ino

// UNO R4: 실습에서는 10-bit(0~1023) 해상도로 명시 설정
void setup() { Serial.begin(115200); analogReadResolution(10); }
void loop() {
  int raw=analogRead(A0);
  float volts=raw*(5.0f/1023.0f); // 5V 기준 가정: 실제 VREF와 오차 가능
  Serial.print("ADC="); Serial.print(raw);
  Serial.print(" approx V="); Serial.println(volts,2);
  delay(200);
}
