02차시 — 디바운스와 토글

README 원본 · 전체 실습 목록

Arduino 전체 목차 · 32차시 테크트리

개요

입력 신호를 읽고 출력 장치를 제어한다. 이전 차시와 비교하여 늘어난 입출력 기능을 확인한다.

준비

  • 대상 보드: Arduino UNO R4 Minima 또는 WiFi. 사용 보드와 포트는 Arduino IDE에서 직접 선택한다.
  • 택트 스위치·점퍼선
  • 부품·모듈 회로도를 확인하고 외부 전원과 GND를 연결한다. LED에는 전류 제한 저항을 넣는다.

배선

D2 ↔ 버튼 ↔ GND; 내장 LED 사용

전체 소스

02_button_toggle.ino

소스 파일은 이 폴더에서 열어 그대로 업로드한다. (README와 .ino를 같은 디렉터리에 배치함)

실행 절차

  • Arduino IDE에서 보드와 USB 포트를 선택한다.
  • 스케치 파일을 열어 컴파일(검증)하고 업로드한다.
  • 입력값을 변화시키면서 출력의 변화를 관찰한다.

예상 결과

30ms 동안 안정된 누름만 감지해 LED 상태를 한 번 전환한다.

확인 및 주의

  • 상태: 소스 작성 / 컴파일 미검증 / 실물 미검증
  • 실제 컴파일 성공 또는 보드 동작을 아직 주장하지 않는다.
  • 모듈의 전원 정격과 실제 배선을 확인한 후 전원을 넣는다.
  • 공통 부품 자료: devices/

전체 스케치 — 02_button_toggle.ino

// 버튼 디바운스 + 누를 때마다 LED 토글 (millis 비차단)
const byte BTN = 2;
bool ledOn = false, stable = HIGH, previous = HIGH;
unsigned long changedAt = 0;
void setup() { pinMode(BTN, INPUT_PULLUP); pinMode(LED_BUILTIN, OUTPUT); }
void loop() {
  bool reading = digitalRead(BTN);
  if (reading != previous) changedAt = millis();
  if (millis() - changedAt >= 30 && reading != stable) {
    stable = reading;
    if (stable == LOW) {
      ledOn = !ledOn;
      digitalWrite(LED_BUILTIN, ledOn ? HIGH : LOW);
    }
  }
  previous = reading;
}
