# 13차시 — PIR 움직임 감지

[Arduino 목차](../../README.md) · [32차시 테크트리](../../ROADMAP.md)

## 개요
PIR 움직임 감지을 Arduino UNO R4의 입출력으로 구현한다. 기본 예제에서 확인한 입력·출력 개념을 이어서 사용한다.

## 준비 및 배선
- 보드: Arduino UNO R4 Minima 또는 WiFi. 실제 보드에 맞게 Arduino IDE 보드와 포트를 선택한다.
- 배선: HC-SR501 VCC→모듈 표기 전원, GND→GND 공통, OUT→D2(출력 전압 확인); 내장 LED 사용
- 주의: 센서 모듈의 OUT 출력 전압을 UNO R4 디지털 입력 허용 범위와 대조합니다.

## 전체 코드
[13_pir_led.ino](13_pir_led.ino) — 이 폴더의 스케치 원본

## 실행 절차
1. Arduino IDE에서 `13_pir_led.ino`를 열고 보드·포트를 선택한다.
2. 필요한 라이브러리를 설치하고 스케치를 검증(컴파일)한 뒤 업로드한다.
3. 배선을 확인하고 입력을 변화시키면서 출력 반응을 관찰한다.
4. Serial 출력이 있는 차시는 115200 baud로 시리얼 모니터를 연다.

## 예상 결과
PIR 출력 HIGH일 때 내장 LED가 켜집니다. 예열 시간과 유지 시간 때문에 반응이 지연될 수 있습니다.

## 검증 상태

- UNO R4 실물 시험: 미실행
- 실제 모듈별 전압·핀 배치 대조: 시험 전 확인 필요
