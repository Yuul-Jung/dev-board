개요

74HC595와 7세그먼트를 Arduino UNO R4의 입출력으로 구현한다. 기본 예제에서 확인한 입력·출력 개념을 이어서 사용한다.

준비 및 배선

  • 보드: Arduino UNO R4 Minima 또는 WiFi. 실제 보드에 맞게 Arduino IDE 보드와 포트를 선택한다.
  • 배선: D2→74HC595 DS, D3→SHCP, D4→STCP; 74HC595 Q0~Q7→각 전류제한저항→7세그 a~g,dp; 공통 캐소드 GND. 74HC595 VCC=5V, GND 공통, /OE=GND, /MR=5V.
  • 주의: 74HC595 출력 핀별·칩 전체 전류 정격을 확인합니다. 고휘도 디스플레이 또는 다자리 구동은 별도 드라이버가 필요합니다.

전체 코드

실행 절차

  • Arduino IDE에서 11_hc595_7segment.ino를 열고 보드·포트를 선택한다.
  • 필요한 라이브러리를 설치하고 스케치를 검증(컴파일)한 뒤 업로드한다.
  • 배선을 확인하고 입력을 변화시키면서 출력 반응을 관찰한다.
  • Serial 출력이 있는 차시는 115200 baud로 시리얼 모니터를 연다.

예상 결과

0~9 숫자가 1초 간격으로 순환 표시됩니다.

전체 스케치 — 11_hc595_7segment.ino

const byte DATA_PIN=2, CLOCK_PIN=3, LATCH_PIN=4;
// Q0..Q6 -> a..g, Q7 -> dp, 공통 캐소드 기준
const byte digits[10]={0x3F,0x06,0x5B,0x4F,0x66,
                       0x6D,0x7D,0x07,0x7F,0x6F};
byte n=0;
unsigned long last=0;
void showDigit(byte v) {
  digitalWrite(LATCH_PIN,LOW);
  shiftOut(DATA_PIN,CLOCK_PIN,MSBFIRST,v);
  digitalWrite(LATCH_PIN,HIGH);
}
void setup() {
  pinMode(DATA_PIN,OUTPUT); pinMode(CLOCK_PIN,OUTPUT);
  pinMode(LATCH_PIN,OUTPUT); showDigit(digits[0]);
}
void loop() {
  if (millis()-last>=1000) {
    last=millis();
    n=(n+1)%10;
    showDigit(digits[n]);
  }
}
