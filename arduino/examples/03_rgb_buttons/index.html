03차시 — 버튼 2개와 RGB LED

Arduino 전체 목차 · 32차시 테크트리

GitHub 에서 이 폴더 보기 · README

Arduino 전체 목차 · 32차시 테크트리

개요

입력 신호를 읽고 출력 장치를 제어한다. 이전 차시와 비교하여 늘어난 입출력 기능을 확인한다.

준비

  • 대상 보드: Arduino UNO R4 Minima 또는 WiFi. 사용 보드와 포트는 Arduino IDE에서 직접 선택한다.
  • 버튼 2개·공통 캐소드 RGB LED·220Ω 저항 3개
  • 부품·모듈 회로도를 확인하고 외부 전원과 GND를 연결한다. LED에는 전류 제한 저항을 넣는다.

배선

D2/D4 ↔ 각 버튼 ↔ GND; D3(적), D5(녹), D6(청) ↔ 각 220Ω ↔ RGB LED 공통 캐소드; 공통 캐소드 → GND

전체 소스

03_rgb_buttons.ino

소스 파일은 이 폴더에서 열어 그대로 업로드한다. (README와 .ino를 같은 디렉터리에 배치함)

실행 절차

  • Arduino IDE에서 보드와 USB 포트를 선택한다.
  • 스케치 파일을 열어 컴파일(검증)하고 업로드한다.
  • 입력값을 변화시키면서 출력의 변화를 관찰한다.

예상 결과

버튼 1은 빨강, 버튼 2는 초록, 둘 다 누르면 파랑, 모두 해제하면 꺼진다.

확인 및 주의

  • 상태: 소스 작성 / 컴파일 미검증 / 실물 미검증
  • 실제 컴파일 성공 또는 보드 동작을 아직 주장하지 않는다.
  • 모듈의 전원 정격과 실제 배선을 확인한 후 전원을 넣는다.
  • 공통 부품 자료: devices/

전체 스케치 — 03_rgb_buttons.ino

// 공통 캐소드 RGB LED. 각 색상 핀에 개별 전류 제한 저항 필수.
const byte B1=2, B2=4, R=3, G=5, B=6;
void setup() {
  pinMode(B1,INPUT_PULLUP); pinMode(B2,INPUT_PULLUP);
  pinMode(R,OUTPUT); pinMode(G,OUTPUT); pinMode(B,OUTPUT);
}
void loop() {
  bool a=digitalRead(B1)==LOW, b=digitalRead(B2)==LOW;
  digitalWrite(R,a&&!b); digitalWrite(G,b&&!a);
  digitalWrite(B,a&&b);
}
