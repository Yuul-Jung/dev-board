# CAN 소자와 SoC 연결

구분: **확인** = 문서를 열어 확인, **계산**, **설계안**, **미확인**.

## 경로 A: AMD AXI CAN (PG096) — 제품 페이지 확인
이전 문서의 "열람한 AMD IP 없음 → 전용 RTL"은 틀렸습니다. 제품 페이지(amd.com, axi_can)를 열어 IP 존재를 확인했고 해당 문구를 고쳤습니다.

| 항목 | 값 | 구분 |
|---|---|---|
| 규격 | ISO 11898-1, CAN 2.0A/2.0B | 확인 |
| 프레임 | 표준 11비트, 확장 29비트 | 확인 |
| 비트율 | 최대 1 Mbps | 확인 |
| 송신 | 메시지 FIFO 최대 64개, 고우선순위 송신 버퍼 1개, 오류·중재 손실 시 자동 재전송 | 확인 |
| 버스 | AXI4-Lite | 확인 |
| 디바이스 | 제품 페이지의 두 목록 모두 Artix 7 포함 (두 목록이 서로 다르게 쓰여 있음) | 확인 |
| 라이선스 | Core License Agreement, Vivado에 포함, 하드웨어 평가판은 약 6시간 후 타임아웃(평가 라이선스) | 확인 |
| 레지스터 맵, 클럭 조건, 비트 타이밍 설정, 수신 FIFO·필터, 자원 사용량 | PG096/DS791 본문을 열지 못함 | **미확인** |
| CAN FD | 언급 없음 (CAN FD 는 별도 IP, PG223) | 미확인 |

주의: 이 IP는 컨트롤러뿐입니다. 버스에 연결하려면 트랜시버 칩이 필요합니다(아래).
평가 라이선스 조건이 실제 사용(상시 동작)에 걸리는지는 Vivado에서 확인해야 합니다. 정식 라이선스 여부는 미확인.

## 경로 B: MCP2515 (SPI) — `../spi/comm-storage-io.md`
컨트롤러가 칩 안에 있어 FPGA는 SPI 만 쓰면 됩니다(AXI Quad SPI). 확인된 사양: CAN 2.0B 1 Mb/s, SPI 10 MHz, 수신 버퍼 2, 송신 버퍼 3. SPI 명령 코드는 미확인.

| 비교 | 경로 A (AXI CAN) | 경로 B (MCP2515) |
|---|---|---|
| 필요 핀 | TX, RX 2핀 + 트랜시버 | SPI 4~5핀 + INT + 트랜시버 |
| FPGA 자원 | IP 사용 | Quad SPI 재사용 가능 |
| 성능 | FIFO 64 | 버퍼 2/3개 |
| 문서 상태 | 레지스터 미확인 | 명령 코드 미확인 |
| 라이선스 | 평가 제한 가능성 | 없음 |

## 트랜시버: SN65HVD230 (TI) — D1 일부 (제품 페이지)
| 항목 | 값 |
|---|---|
| 전원 | 3.3 V 단일 (VCC 3~3.6 V) |
| 속도 | 최대 1 Mbps |
| RS 핀(8번) | GND = 고속, 저항으로 슬로프 제어, 저전력 대기(청취 전용, 전형 370 µA) |
| 규격 | ISO 11898-2 호환 |
| 버스 | 버스 고장 전압 -4~16 V, 공통 모드 범위 -2~7 V, 버스 핀 ESD 16 kV HBM 초과, 최대 120 노드 |
| 핀 이름 매핑, 종단저항 값 | 제품 페이지에 없음 — 미확인 |

3.3 V 소자라 FPGA 와 직결 가능(설계안). 종단 저항은 버스 양 끝에 두는 것이 일반적이나 값은 이번에 확인하지 못했습니다.

## 핀 예산 (설계안)
경로 A: TX, RX 2핀. 경로 B: SPI 버스 공유 + CS + INT.
