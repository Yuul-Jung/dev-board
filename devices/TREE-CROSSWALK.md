# 세 체계 대조: 교재 목차 ↔ Arduino 32차시 ↔ 테크트리 32차시

<!-- nav -->[저장소 홈](../README.md) › [devices](README.md)

아두이노 교재 목차(31장)와 [Arduino 32차시](../arduino/ROADMAP.md)를 뼈대로 삼아, 프로젝트 문서의 기존 테크트리(FPGA/SoC 32차시, [SESSION-MAP.md](SESSION-MAP.md))와 **주제 단위로** 맞춘 표입니다. `tools/gen_crosswalk.py` 가 `data/crosswalk.csv` 에서 만들고, 세 체계의 모든 번호가 한 행 이상에 들어 있는지 검사합니다.

- 세 체계의 번호는 서로 다릅니다. 이 표만이 대응을 보여 줍니다(예: Arduino 09차시 = 테크트리 대응 없음, 테크트리 09차시 = 서보).
- **주제 묶기는 제목을 보고 한 설계안**입니다. 교재 본문은 보지 못했습니다([BOOK-MAP](BOOK-MAP.md)).
- 모듈 상태는 [STATUS.md](STATUS.md) 기준(호스트 모의 시험까지, 보드·RTL 시뮬레이션 0건)이며 소속 모듈 중 가장 낮은 값입니다.

- millis 비차단 타이머 — G01 완비 · 테크트리에 대응 없음(AXI Timer 로 구현)
- 부저·소리 — G08 문서만 · Arduino 쪽 범위(멜로디)와 스케치 불일치. 부저 사양 미확인
- 74HC595·7세그먼트 — 모듈 없음 · 모듈 행 없음. spi/comm-storage-io.md 에 74HC595 언급
- LCD1602(I2C) — I07 완비 · 테크트리에 대응 없음
- 스테퍼 28BYJ-48 — P06 완비 · 테크트리에 대응 없음
- 센서 기반 모터 제어 — T01 완비, P02 완비 · Arduino 쪽만 있는 통합 과제
- CAN·RS-485 — F02 완비, F01 문서만 · 테크트리에 차시 없음(모듈 F01·F02 만 있음)

## 3. 읽는 법

- 「테크트리에만 있음」은 Arduino 로 먼저 익힐 차시가 없다는 뜻이라 RTL 실습 전에 참조 동작을 얻을 곳이 없습니다. Arduino 차시 추가 또는 공통 자료 보강 후보입니다.
- 「Arduino 쪽에만 있음」은 RTL 로 옮길 대상이 테크트리에 없다는 뜻입니다. 필요하면 테크트리에 차시를 더하거나, Arduino 전용으로 둘지 결정해야 합니다(미결).
