# 아두이노 모듈 현황 (구조화·순서화)

<!-- nav -->[저장소 홈](../README.md) › [devices](README.md)

이 문서는 `data/module-status.csv`(모듈 72종)와 `data/chapter-status.csv`(교재 장)에서 만든 표입니다. 두 CSV 는 대시보드와 같은 자료입니다. 근거 등급: 계산(저장소 파일 유무를 스크립트로 대조) / 확인되지 않은 것은 해당 칸에 적음.

## 1. 판정 기준 (위에서 아래 순서로 따짐)

| 순서 | 상태 | 조건 |
|---|---|---|
| 1 | 완비 | 소자 문서 + 드라이버 C + 그 드라이버를 부르는 호스트 시험이 모두 있음 |
| 2 | 일부 | 드라이버나 RTL 은 있으나 호스트 시험이 없거나, 시뮬레이션·보드 확인 전 |
| 3 | 문서만 | 문서(또는 조사)만 있고 전용 드라이버·시험 없음 |
| 4 | 없음 | 문서도 드라이버도 없음 |

호스트 시험은 직접 만든 모의 장치를 상대로 한 것이라 데이터시트 해석이 틀리면 같이 틀립니다. 보드 실행과 Verilog 시뮬레이션은 하나도 없습니다.

## 6. 이번 검증에서 바로잡은 것

처음 정리본(대시보드 1판)은 「완비」를 30종으로 셌습니다. 드라이버 C 가 시험 파일에서 한 번이라도 쓰이는지 전부 대조하자 다음이 틀렸습니다.

- 드라이버는 있는데 호스트 시험이 없음: `1-wire/sw/ds18b20.c`, `gpio/sw/dht22.c`, `gpio/sw/ultrasonic.c` → 일부로 내림(T01 W01 C01). Verilog tb 는 있으나 시뮬레이터가 없어 한 번도 돌리지 못했습니다.
- 전용 드라이버·시험이 없음: HC-SR501(G02), 릴레이(G09) → 문서만으로 내림.
- 조사 문서가 있는데 「없음」으로 셌음: microSD(S02), ENC28J60(S10) → 문서만으로 올림.
- MCP2515 가 S11 과 F02 로 두 번 들어 있음(중복). F02 메모에 표시했고 개수는 그대로 둡니다.
