# DS18B20 디지털 온도 센서

<!-- nav -->[저장소 홈](../../README.md) › [devices](../README.md) › [1-wire](README.md)
- 분류: 온도 · 인터페이스: 1-Wire · 근거: D1 (Analog Devices 데이터시트)

## 전기 사양 (확인)
| 항목 | 값 |
|---|---|
| 공급 전압 | 3.0–5.5 V (외부 전원 시) |
| 측정 범위 | -55–+125 °C |
| 정확도 | ±0.5 °C(-10–+85 °C), ±1 °C(-30–+100 °C), ±2 °C(-55–+125 °C) |
| 분해능 | 9–12비트 선택(0.5 / 0.25 / 0.125 / 0.0625 °C), 전원 인가 시 12비트 |
| 변환 시간 | 12비트에서 최대 750 ms |
| 고유 ID | 64비트 ROM 코드, 패밀리 코드 28h |
| 버스 | DQ 1선 + GND, 오픈 드레인, 외부 풀업 약 5 kΩ |
| 기생 전원 | DQ와 GND만으로 동작 가능(이때 VDD는 GND) |
| 알람 | Alarm Search(ECh)로 TL 이하 또는 TH 이상인 소자 검색 |

명령 코드: Convert T 44h · Read Scratchpad BEh · Skip ROM CCh · Match ROM 55h · Search ROM F0h

## SoC 연결 (Basys3 + MicroBlaze V)
| 항목 | 내용 | 구분 |
|---|---|---|
| 핀 | DQ 1핀 양방향 + 풀업 | 확인 |
| AMD IP | 열람한 1-Wire용 AMD IP 없음 | 확인(부재는 미확인 포함) |
| 구현 A | AXI GPIO의 비트별 방향(TRI)으로 오픈 드레인 흉내: 0 출력 또는 입력으로 해제 | 설계안 (TRI 기능은 PG144 확인) |
| 구현 B | 1-Wire 마스터 RTL + AXI4-Lite 레지스터 | 설계안 |
| 다중 소자 | 한 버스에 여러 개, Search ROM으로 ID 열거 | 확인 |
| 변환 대기 | 750 ms 동안 폴링하거나 타이머 인터럽트 사용 | 설계안 |

## 1-Wire 슬롯 타이밍 (확인, AC 표)
| 항목 | 최소 | 최대 |
|---|---|---|
| 리셋 Low tRSTL / High tRSTH | 480 µs | |
| Presence High tPDHIGH | 15 µs | 60 µs |
| Presence Low tPDLOW | 60 µs | 240 µs |
| 쓰기 0 Low tLOW0 | 60 µs | 120 µs |
| 쓰기 1 Low tLOW1 | 1 µs | 15 µs |
| 슬롯 tSLOT | 60 µs | 120 µs |
| 회복 tREC | 1 µs | |
| 읽기 데이터 유효 tRDV | | 15 µs |

읽기 슬롯은 마스터 Low가 1 µs보다 길어야 하고, tINIT+tRC+tSAMPLE이 15 µs보다 짧아야 하며, 15 µs 구간 끝에 가깝게 샘플하라고 권장됩니다.

## 전용 RTL
AMD IP가 없어 `rtl/`에 AXI4-Lite 1-Wire 마스터를 설계했습니다. 레지스터와 타이밍 선택 근거는 `rtl/README.md`.

## 드라이버 (`sw/ds18b20.[ch]`)
리셋 → Skip ROM → Convert T → 읽기 슬롯이 1 이 될 때까지 폴링 → 스크래치패드 9바이트 읽기 → CRC 검사 → µ°C 로 변환. 설정 바이트의 해상도(9~12비트)에 따라 정의되지 않은 하위 비트를 버립니다. 기생 전원은 지원하지 않습니다(변환 상태 비트를 읽을 수 없어 시간 초과로 끝남).

| 사실 | 값 | 근거 |
|---|---|---|
| 스크래치패드 | 0,1 온도 LSB/MSB, 2 TH, 3 TL, 4 설정, 5~7 예약, 8 CRC | 확인 D1 요약 경유 |
| 설정 바이트 | 비트 6:5 = R1R0, 9/10/11/12비트 = 1Fh/3Fh/5Fh/7Fh | 확인(값은 비트 배치에서 유도: 계산) |
| 전원 투입 온도 | +85 °C (0550h) | 확인 |
| 변환 시간 | 93.75 / 187.5 / 375 / 750 ms | 확인 |
| CRC | x^8+x^5+x^4+1, 스크래치패드 0~7 | 확인 |
| 미정의 비트 | 9/10/11비트일 때 하위 3/2/1비트 | 확인 |
| 예약 바이트 5~7 | 본문 "모두 1" 대 표 FFh,0Ch,10h | 문서 안에서 갈림(드라이버는 값을 보지 않음) |

## 근거와 한계
스크래치패드·CRC·설정 바이트는 데이터시트 사본(웹 가져오기 요약 경유)으로 확인했고 PDF 원문은 직접 열지 못했습니다. 드라이버는 호스트 모의 소자 시험만 통과했으며(모의 소자는 내가 해석해서 만든 것이라 순환), RTL은 시뮬레이션·합성 전, 보드 실행도 없습니다.
