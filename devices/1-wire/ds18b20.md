# DS18B20 디지털 온도 센서

<!-- nav -->[저장소 홈](../../README.md) › [devices](../README.md) › [1-wire](README.md)
- 분류: 온도 · 인터페이스: 1-Wire · 근거: D1 (Analog Devices 데이터시트)

## 전기 사양 (확인)
| 항목 | 값 |
|---|---|
| 공급 전압 | 3.0–5.5 V (외부 전원 시) |
| 측정 범위 | -55–+125 °C |
| 정확도 | ±0.5 °C(-10–+85 °C), ±1 °C(-30–+100 °C), ±2 °C(-55–+125 °C) |
| 분해능 | 9–12비트 선택(0.5 / 0.25 / 0.125 / 0.0625 °C), 전원 인가 시 12비트 |
| 변환 시간 | 12비트에서 최대 750 ms |
| 고유 ID | 64비트 ROM 코드, 패밀리 코드 28h |
| 버스 | DQ 1선 + GND, 오픈 드레인, 외부 풀업 약 5 kΩ |
| 기생 전원 | DQ와 GND만으로 동작 가능(이때 VDD는 GND) |
| 알람 | Alarm Search(ECh)로 TL 이하 또는 TH 이상인 소자 검색 |

명령 코드: Convert T 44h · Read Scratchpad BEh · Skip ROM CCh · Match ROM 55h · Search ROM F0h

## SoC 연결 (Basys3 + MicroBlaze V)
| 항목 | 내용 | 구분 |
|---|---|---|
| 핀 | DQ 1핀 양방향 + 풀업 | 확인 |
| AMD IP | 열람한 1-Wire용 AMD IP 없음 | 확인(부재는 미확인 포함) |
| 구현 A | AXI GPIO의 비트별 방향(TRI)으로 오픈 드레인 흉내: 0 출력 또는 입력으로 해제 | 설계안 (TRI 기능은 PG144 확인) |
| 구현 B | 1-Wire 마스터 RTL + AXI4-Lite 레지스터 | 설계안 |
| 다중 소자 | 한 버스에 여러 개, Search ROM으로 ID 열거 | 확인 |
| 변환 대기 | 750 ms 동안 폴링하거나 타이머 인터럽트 사용 | 설계안 |

## 1-Wire 슬롯 타이밍 (확인, AC 표)
| 항목 | 최소 | 최대 |
|---|---|---|
| 리셋 Low tRSTL / High tRSTH | 480 µs | |
| Presence High tPDHIGH | 15 µs | 60 µs |
| Presence Low tPDLOW | 60 µs | 240 µs |
| 쓰기 0 Low tLOW0 | 60 µs | 120 µs |
| 쓰기 1 Low tLOW1 | 1 µs | 15 µs |
| 슬롯 tSLOT | 60 µs | 120 µs |
| 회복 tREC | 1 µs | |
| 읽기 데이터 유효 tRDV | | 15 µs |

읽기 슬롯은 마스터 Low가 1 µs보다 길어야 하고, tINIT+tRC+tSAMPLE이 15 µs보다 짧아야 하며, 15 µs 구간 끝에 가깝게 샘플하라고 권장됩니다.

## 모듈별 실물 연결 기준 (2026-11-03 제조사 원문 재확인)

| 제품 구분 | 실제 연결·전원 | Basys3 연결 판정 |
|---|---|---|
| DS18B20 단품 TO-92 | 칩 핀 1=GND, 2=DQ, 3=VDD(패키지 핀 번호; 앞·뒤 방향은 데이터시트 그림 확인). 외부 전원 3.0~5.5 V | **3.3 V VDD + DQ를 3.3 V로 풀업**하는 외부 전원 방식 우선. GND 공통. |
| Keyestudio KS0329 방수 프로브 | 3.3~5 V 전원, 별도 **4.7 kΩ 풀업 저항 동봉**. 신호선 색상은 KS0329 설명에서 노랑 | 판매 변형·배선 색상·실물 전압 확인 후 3.3 V DQ로 연결 |
| Seeed Grove One Wire Temperature Sensor | DS18B20 방수 프로브 + Grove 기판, **풀업 저항 실장**, 3.0~5.5 V | Grove 커넥터의 전원 레일/신호 순서를 확인하고 **3.3 V로 전원·풀업**. 5 V Grove 커넥터를 FPGA에 직결 금지 |
| Keyestudio KS0124 EASY plug | **RJ11 6P6C** 전용 커넥터, 3.3~5 V. 제조사가 타사 RJ11 핀 순서 호환을 보장하지 않음 | RJ11을 Pmod 1-Wire와 동일 핀맵으로 취급 금지. 별도 핀 매핑 확인 전 연결 금지 |
| 국내·AliExpress 범용 3핀 기판 | DS18B20 칩이 같아도 기판 풀업의 연결 레일, 전원, 핀 배열이 다를 수 있음 | 구매 제품의 회로도·실물 측정 없이는 GPIO 직결 승인 금지 |

- **전압 주의:** DS18B20 자체가 5 V 동작을 지원하더라도 **DQ가 5 V로 풀업된 버스는 Basys3 3.3 V GPIO에 연결하면 안 됩니다.** 이 버스는 I²C가 아니라 **1-Wire**이며, XADC(단극성 일반 입력 0~1 V)와도 별개입니다.
- **풀업 주의:** 4.7 kΩ은 제조사 데이터시트 그림의 전형적 예시입니다. 기판에 이미 저항이 있는지 확인해 중복 풀업의 합성 저항·전류를 검토합니다.
- **전원 방식:** 현재 RTL/드라이버는 외부 VDD 공급만 대상으로 합니다. 기생 전원(Parasite Power)은 변환 시작 후 10 µs 안에 **강한 풀업**이 필요하므로 기존 오픈드레인 해제 기능만으로 지원한다고 표시하지 않습니다.
- **핀 구분:** TO-92 패키지 핀 번호와 방수 프로브 케이블 색상, Grove 4핀, EASY plug RJ11은 서로 다른 기준입니다. 부품 식별 없이 색상만으로 배선하지 않습니다.

**공식 원문:** [Analog Devices DS18B20 Rev.6 (2019-07) PDF](https://www.analog.com/media/en/technical-documentation/data-sheets/ds18b20.pdf), [Arduino 1-Wire 설명](https://github.com/arduino/docs-content/blob/475b308dd2c9d7e6783b3dbdc9626b848a454ecd/content/learn/05.communication/06.one-wire/one-wire.md), [Keyestudio KS0329](https://docs.keyestudio.com/projects/KS0329/en/latest/docs/KS0329.html), [Keyestudio KS0124](https://docs.keyestudio.com/projects/KS0124/en/latest/docs/KS0124.html), [Seeed Grove DS18B20](https://wiki.seeedstudio.com/One-Wire-Temperature-Sensor-DS18B20/). 원본 그림·코드의 라이선스를 일괄 허용된 것으로 보지 않으며 복제하지 않습니다.

## 전용 RTL
AMD IP가 없어 `rtl/`에 AXI4-Lite 1-Wire 마스터를 설계했습니다. 레지스터와 타이밍 선택 근거는 `rtl/README.md`.

## 드라이버 (`sw/ds18b20.[ch]`)
리셋 → Skip ROM → Convert T → 읽기 슬롯이 1 이 될 때까지 폴링 → 스크래치패드 9바이트 읽기 → CRC 검사 → µ°C 로 변환. 설정 바이트의 해상도(9~12비트)에 따라 정의되지 않은 하위 비트를 버립니다. 기생 전원은 지원하지 않습니다(변환 상태 비트를 읽을 수 없어 시간 초과로 끝남).

| 사실 | 값 | 근거 |
|---|---|---|
| 스크래치패드 | 0,1 온도 LSB/MSB, 2 TH, 3 TL, 4 설정, 5~7 예약, 8 CRC | 확인 D1 요약 경유 |
| 설정 바이트 | 비트 6:5 = R1R0, 9/10/11/12비트 = 1Fh/3Fh/5Fh/7Fh | 확인(값은 비트 배치에서 유도: 계산) |
| 전원 투입 온도 | +85 °C (0550h) | 확인 |
| 변환 시간 | 93.75 / 187.5 / 375 / 750 ms | 확인 |
| CRC | x^8+x^5+x^4+1, 스크래치패드 0~7 | 확인 |
| 미정의 비트 | 9/10/11비트일 때 하위 3/2/1비트 | 확인 |
| 예약 바이트 5~7 | 본문 "모두 1" 대 표 FFh,0Ch,10h | 문서 안에서 갈림(드라이버는 값을 보지 않음) |

## 근거와 한계
전기 사양·핀 번호·1-Wire 타이밍·기생 전원 강한 풀업 요구는 Analog Devices Rev.6 PDF 원문을 2026-11-03 확인했습니다. 스크래치패드·CRC 등 세부 구현은 별도 회귀시험이 필요합니다. 드라이버는 호스트 모의 소자 시험만 통과했으며(모의 소자는 내가 해석해서 만든 것이라 순환), RTL은 시뮬레이션·합성 전, 보드 실행도 없습니다.
