# ADS1115 (16비트 I2C ADC)

<!-- nav -->[저장소 홈](../../README.md) › [devices](../README.md) › [i2c](README.md)

드라이버: [`sw/ads1115.h`](sw/ads1115.h), [`sw/ads1115.c`](sw/ads1115.c). 시험: [`tb/test_ads1115.c`](tb/test_ads1115.c). 근거는 TI SBAS444 데이터시트 웹 문서(D1; 영문판 Config 절, 일문판 I2C·사양 절). PDF 를 직접 열지는 못했습니다.

## 확인한 사양
| 항목 | 값 |
|---|---|
| 7비트 주소 | ADDR→GND 0x48, VDD 0x49, SDA 0x4A, SCL 0x4B (SDA 로 정할 때 SCL 하강 후 SDA 를 100 ns 이상 Low 유지) |
| 포인터 | 00 변환값, 01 Config(리셋 8583h), 10 Lo_thresh(8000h), 11 Hi_thresh(7FFFh) |
| 바이트 순서 | 쓰기·읽기 모두 MSB 먼저 |
| Config | OS[15] MUX[14:12] PGA[11:9] MODE[8] DR[7:5] COMP_MODE[4] COMP_POL[3] COMP_LAT[2] COMP_QUE[1:0] |
| MUX | 000 AIN0-1, 001 AIN0-3, 010 AIN1-3, 011 AIN2-3, 100~111 AIN0~3 대 GND |
| PGA / LSB | ±6.144 V 187.5 µV, ±4.096 V 125 µV, ±2.048 V 62.5 µV(리셋), ±1.024 V 31.25 µV, ±0.512 V 15.625 µV, ±0.256 V 7.8125 µV |
| 데이터 속도 | 8, 16, 32, 64, 128(리셋), 250, 475, 860 SPS. 변환 시간 = 1/DR |
| 출력 | 16비트 2의 보수, +FS = 7FFFh, −FS = 8000h, 범위를 넘으면 포화 |
| 단발 | MODE=1 에서 OS=1 쓰기로 시작. 읽을 때 OS=0 이면 변환 중, 1 이면 끝 |
| 전원·아날로그 입력 | VDD 2.0~5.5 V. **정상 동작 권장 범위: 각 AIN 핀 GND~VDD**. **절대최대 정격: GND−0.3 V~VDD+0.3 V**(정상 측정 범위 아님). TI SBAS444E §5.1/§5.3 |
| SCL | 400 kHz, 고속 모드 3.4 MHz(이 드라이버는 400 kHz 이하 가정) |

## 설계 메모 (설계안)
- **P0 전압 정정:** ADS1115를 3.3 V로 구동할 때 **AIN 정상 측정 입력은 0~3.3 V 이내**로 설계합니다. 3.6 V는 절대최대 정격(VDD+0.3 V)이므로 정상 측정 허용치가 아닙니다. PGA의 ±4.096 V·±6.144 V는 **코드 스케일**이며 해당 전압을 AIN에 인가할 수 있다는 뜻이 아닙니다(TI §5.1/§5.3/§7.3.3). 단일 종단 측정은 0~min(VDD,+FSR)이고 양수 측 절반 코드 범위를 사용합니다.
- 단발 변환은 1 ms 간격으로 최대 200회(200 ms) 폴링합니다. 8 SPS 의 125 ms 보다 길게 잡았습니다(상한은 설계안).
- 비교기·ALERT/RDY 는 COMP_QUE=11 로 비활성화합니다(리셋 기본값과 같음). 사용하려면 GPIO 인터럽트 설계가 필요합니다.
- `ads1115_raw_to_uv` 는 raw×FSR/32768 을 0 쪽으로 내림합니다(187.5 µV → 187).

## 2026-11-02 보드 변형·핀·전기적 연결 교차 검증

**원본 칩과 판매 모듈은 다른 전기적 설계 대상**입니다. Arduino UNO R4 Minima는 5 V I/O 보드이므로 그 실습의 I²C 배선을 Basys3 3.3 V I/O로 그대로 복사하지 않습니다([Arduino 공식 Hardware Docs](https://docs.arduino.cc/hardware/uno-r4-minima), D1).

| 제품·근거 | 전원·버스 | 실제 핀·보드 차이 | Basys3 연결 판단 |
|---|---|---|---|
| [TI ADS1115 IC](https://www.ti.com/document-viewer/ADS1115/datasheet) (SBAS444E Rev.E, 2024-12) | 칩 VDD 2.0~5.5 V, I²C | **AIN0~AIN3** 아날로그, **SDA/SCL** 버스, **ADDR** 주소 선택, **ALERT/RDY** 비교기 출력, VDD/GND | 3.3 V VDD 권장(설계안). **SDA/SCL 풀업이 3.3 V인지 별도 확인** |
| [Seeed Grove 4-channel ADS1115](https://wiki.seeedstudio.com/Grove-16-bit-ADC-ADS1115/) | 제조사 문서 3.3/5 V 지원, I²C 기본 0x48 | Grove 연결부의 아날로그 **A0/A1은 나사 단자의 A0/A1과 공유**. 별도 Grove I²C 포트 사용 | 5 V 사용 시 풀업 전원·레벨 변환·커넥터 핀 순서를 회로도로 확인하기 전 직결 금지 |
| [DFRobot Gravity ADS1115 DFR0553](https://www.dfrobot.com/product-1730.html) | VCC 3.3~5.0 V, 제조사 표기 I²C HIGH **3.3 V** | **4채널 AIN** + Gravity **4선 I²C**(VCC/GND/SDA/SCL), 주소 선택 스위치로 **두 주소** 선택 | 3.3 V HIGH는 **DFR0553 보드 제조사 주장**이며 모든 ADS1115 보드에 일반화 불가. 실제 핀 순서·HIGH 측정 필요 |
| 국내 [VCTEC 판매 DFR0553](https://vctec.co.kr/product/16%EB%B9%84%ED%8A%B8-i2c-adc-%EB%AA%A8%EB%93%88-ads1115-gravity-i2c-ads1115-16-bit-adc-module-arduino-/13354/) | 제조사 사양을 판매 페이지에 기재 | DFRobot Gravity 보드. **범용 10핀 ADS1115 브레이크아웃과 다름** | 판매 문구는 D3; 실제 수령 제품·회로도·I²C 전압 확인 전 승인하지 않음 |

- **P0: FPGA I/O 3.3 V** — I²C는 오픈드레인 방식이므로 **SDA/SCL 외부·온보드 풀업의 연결 전압**을 확인해야 합니다. 5 V 풀업이 존재하면 Basys3에 직접 연결하지 않습니다. TI 칩의 디지털 핀 절대최대 정격과 **Basys3 GPIO 입력 정격은 별개**입니다.
- **P0: 아날로그 전압** — 5 V 센서의 출력이나 ±6.144 V PGA 설정을 근거로 5 V를 3.3 V 전원 ADS1115 AIN에 직접 인가하지 않습니다. ADC 전원과 센서 출력의 공통 접지·입력 범위·분압·입력 임피던스를 검토합니다.
- **P0: XADC 혼동 금지** — ADS1115의 외부 아날로그 AIN(정상 0~VDD)과 Basys3 **내장 XADC 일반 단극성 0~1 V 입력**은 서로 다른 물리 핀·전압 범위입니다. ADS1115의 3.3 V 센서 신호를 XADC 핀에 연결하지 않습니다.
- **P1: 주소·핀** — TI 원본 칩은 ADDR을 GND/VDD/SDA/SCL에 연결하여 0x48/0x49/0x4A/0x4B를 선택하지만, DFR0553은 **보드 스위치로 두 주소**만 선택한다고 제조사가 명시합니다. 원본 IC의 4주소 지원을 모든 모듈의 외부 스위치 기능으로 오해하지 않습니다.
- **P1: 코드·시뮬레이션** — 기존 `sw/ads1115.c`와 `tb/test_ads1115.c`는 Config 비트·MSB 순서·원시 코드 환산을 모의 검증하는 구현이며, **전압 초과 방지나 실제 I²C 풀업/레벨 검사는 할 수 없습니다**. 외부 ADC를 사용해도 AXI IIC(SoC) 연결과 순수 RTL I²C 마스터는 별도 구현 경로입니다.
- **출처·라이선스** — TI/Arduino/Seeed/DFRobot 공식 페이지는 링크·열람일만 기록합니다(웹 페이지에 Git SHA 없음). [Seeed ADS1115 Arduino 라이브러리](https://github.com/Seeed-Studio/Seeed_Arduino_ADS1115/tree/00beed48708bae7cce1f78ad05448e1af132e0a3) 및 [DFRobot ADS1115 라이브러리](https://github.com/DFRobot/DFRobot_ADS1115/tree/6d3df78d29693bf9e245a223afe0443406bd2980)는 **MIT 라이선스 파일 확인**. 원본 이미지·코드를 이 저장소에 복제하지 않음.

## 시험과 한계
- 공개 레지스터 API의 NULL 장치·버스·출력 포인터는 `IIC_ERR_ARGS`를 반환하도록 수정하고, 회귀 테스트 5건을 추가했습니다. 실제 시험 실행 결과는 CI 확인 전까지 **미확인**입니다.
- I2C 층을 데이터시트 규칙으로 만든 모델로 바꿔 검사: 주소 범위·NACK, Config 레지스터 왕복, 0xC283 비트 배치, 단발 폴링, 시간 초과, mux 8 × PGA 6 × DR 8 = 384 조합에서 필드 위치, LSB 표와의 일치. ASan/UBSan 통과. 바이트 순서·필드 위치·OS 판정을 일부러 틀리게 한 사본은 모두 실패로 잡힘.
- 모델은 내가 읽은 문서대로 내가 만든 것이라 문서 해석이 틀리면 같이 틀립니다. 보드에서 실행하지 않았습니다.
- 미확인·미작성: 일반 호출 리셋, 고속 모드 절차, 임계값 레지스터 사용, 실제 변환 지연(1/DR 이외의 시작 지연).
