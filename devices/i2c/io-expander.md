# I/O 확장기: PCF8574, MCP23017

<!-- nav -->[저장소 홈](../../README.md) › [devices](../README.md) › [i2c](README.md)

드라이버: [`sw/io_expander.h`](sw/io_expander.h), [`sw/io_expander.c`](sw/io_expander.c). 시험: [`tb/test_io_expander.c`](tb/test_io_expander.c). 근거는 PCF8574 = TI SCPS068, MCP23017 = Microchip 데이터시트(D1, 본문 요약을 읽음).

## PCF8574 (8비트, 준양방향)
| 항목 | 값 (확인) |
|---|---|
| 7비트 주소 | 0x20 + (A2A1A0) → 0x20~0x27. 일반 호출에는 응답하지 않음 |
| 접근 | 레지스터 없음. 쓰기 = 주소 뒤 바이트 하나가 핀 전체(이후 바이트는 무시), 읽기 = 핀 상태 한 바이트 |
| 전원 투입 | 모든 핀 High (약한 전류원 100 µA 급) |
| 입력으로 쓰기 | 그 비트에 먼저 1 을 써 둘 것 |
| 인터럽트 | INT 오픈 드레인, 입력 핀 변화 시 Low, 포트를 읽거나 쓰면 해제 |
| 전원·전류 | VCC 2.5~6 V, 핀 싱크 권장 25 mA 이하(절대 최대 50 mA), 소스 권장 −1 mA 이하 |
| SCL | 100 kHz 규격(Rp 절에서 400 kHz 언급) |
- **PCF8574A** 는 열어본 문서에 없어 미확인(주소 대역이 다른 변형으로 알려져 있으나 이 저장소에서는 확인하지 않음). 드라이버는 0x20~0x27 만 허용.
- LED를 구동할 때는 핀이 소스보다 싱크가 강하므로 핀을 Low 로 끌어 LED 를 켜는 배선이 안전(데이터시트의 전류 한계에서 도출한 설계안).

## MCP23017 (16비트, IOCON.BANK=0 지도)
| 레지스터 | A / B | 리셋값 |
|---|---|---|
| IODIR | 00h / 01h | FFh (전부 입력) |
| IPOL, GPINTEN, DEFVAL, INTCON | 02/03, 04/05, 06/07, 08/09 | 00h |
| IOCON | 0Ah (0Bh 도 같은 레지스터) | 00h |
| GPPU | 0Ch / 0Dh | 00h |
| INTF, INTCAP | 0E/0F, 10/11 | 00h |
| GPIO, OLAT | 12/13, 14/15 | 00h |
- IOCON 비트: 7 BANK, 6 MIRROR, 5 SEQOP, 4 DISSLW, 3 HAEN, 2 ODR, 1 INTPOL, 0 미사용.
- 주소 0100 A2A1A0 → 0x20~0x27. SEQOP=0 이면 포인터가 자동 증가하고 마지막 레지스터 뒤에서 00h 로 돌아감. 쓰기는 정지/재시작 전에 끊기면 반영되지 않음.
- VDD 1.8~5.5 V. SCL 100/400 kHz, 1.7 MHz 고속 모드는 4.5~5.5 V·확장 온도급에서만. 내부 풀업 약 100 kΩ, 핀당 소스/싱크 25 mA. RESET 은 Low 1 µs 이상.
- 드라이버: 초기화 시 IOCON=0(BANK=0, SEQOP=0)을 씀. 16비트 함수는 A,B 를 한 트랜잭션으로 처리. 출력은 OLAT 에, 읽기는 GPIO 에서 함(OLAT/GPIO 의미는 레지스터 이름에서 한 해석이며 설계안).
- **BANK=1 이었던 장치**는 IOCON 주소가 달라서 초기화가 엉뚱한 레지스터에 쓴다 → RESET 핀으로 되돌린 뒤 사용. BANK=1 지도는 이번에 확인하지 않음.

## 시험과 한계
- I2C 층을 위 규칙으로 만든 모델로 바꿔 검사(주소 범위, 래치/핀 상태 차이, 자동 증가 바이트 순서, 실패 시 상태 유지). ASan/UBSan 통과. 바이트 순서·OLAT↔GPIO 레지스터·비트 연산을 틀리게 한 사본은 실패로 잡힘.
- 모델은 내가 읽은 문서대로 내가 만든 것이라 해석이 틀리면 같이 틀립니다. 보드에서 실행하지 않았습니다.
- 미작성·미확인: 인터럽트 설정(GPINTEN/INTCON/DEFVAL 의미), BANK=1, HAEN(MCP23S17용), PCF8574A.
