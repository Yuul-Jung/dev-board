# BME280 습도·압력·온도 센서
- 분류: 환경 · 인터페이스: I2C / SPI · 근거: D1 (Bosch 데이터시트 Rev. 1.6 사본)

## 전기 사양 (확인)
| 항목 | 값 |
|---|---|
| VDD / VDDIO | 1.71–3.6 V / 1.2–3.6 V |
| I2C 주소 | 0x76(SDO=GND), 0x77(SDO=VDDIO) |
| I2C 속도 | 최대 3.4 MHz |
| SPI | 4선·3선, 최대 10 MHz |
| 습도 | 0–100 %RH, ±3 %RH(20–80 %RH, 25 °C) |
| 압력 | 300–1100 hPa, ±1.0 hPa(0–65 °C) |
| 온도 | 동작 -40–+85 °C, 정확도 ±1.0 °C는 0–65 °C |
| 모드 | Sleep / Forced / Normal |
| 칩 ID | 레지스터 0xD0 = 0x60 |
| 전류 | 습도+압력+온도 1 Hz에서 3.6 µA, Sleep 0.1 µA |

## SoC 연결 (Basys3 + MicroBlaze V)
| 항목 | 내용 | 구분 |
|---|---|---|
| 전압 | 최대 3.6 V이므로 Basys3 Pmod 3.3 V와 맞음 | 계산 |
| I2C 경로 | AXI IIC: 100 kHz / 400 kHz / 1 MHz 모드. 센서 한도 3.4 MHz보다 낮으므로 IP 한도가 속도 상한 | 확인(두 문서 비교) |
| 핀 | SCL, SDA 2핀 + 풀업 | 확인 |
| SPI 경로 | AXI Quad SPI(PG153), 4핀 | 확인(IP 존재), 구성은 설계안 |
| 통신 확인 | 0xD0을 읽어 0x60이 오는지 검사 | 확인(값) |
| 보정 | 소자별 보정 계수를 읽어 소프트웨어에서 계산 | 설계안 (계수 레지스터는 미기록) |

## 근거와 한계
보정 계수 위치와 계산식, 오버샘플링 설정 레지스터는 이번에 기록하지 않음.
