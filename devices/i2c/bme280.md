# BME280 습도·압력·온도 센서
- 분류: 환경 · 인터페이스: I2C / SPI · 근거: D1 (Bosch 데이터시트 Rev. 1.6 사본)

## 전기 사양 (확인)
| 항목 | 값 |
|---|---|
| VDD / VDDIO | 1.71–3.6 V / 1.2–3.6 V |
| I2C 주소 | 0x76(SDO=GND), 0x77(SDO=VDDIO) |
| I2C 속도 | 최대 3.4 MHz |
| SPI | 4선·3선, 최대 10 MHz |
| 습도 | 0–100 %RH, ±3 %RH(20–80 %RH, 25 °C) |
| 압력 | 300–1100 hPa, ±1.0 hPa(0–65 °C) |
| 온도 | 동작 -40–+85 °C, 정확도 ±1.0 °C는 0–65 °C |
| 모드 | Sleep / Forced / Normal |
| 칩 ID | 레지스터 0xD0 = 0x60 |
| 전류 | 습도+압력+온도 1 Hz에서 3.6 µA, Sleep 0.1 µA |

## SoC 연결 (Basys3 + MicroBlaze V)
| 항목 | 내용 | 구분 |
|---|---|---|
| 전압 | 최대 3.6 V이므로 Basys3 Pmod 3.3 V와 맞음 | 계산 |
| I2C 경로 | AXI IIC: 100 kHz / 400 kHz / 1 MHz 모드. 센서 한도 3.4 MHz보다 낮으므로 IP 한도가 속도 상한 | 확인(두 문서 비교) |
| 핀 | SCL, SDA 2핀 + 풀업 | 확인 |
| SPI 경로 | AXI Quad SPI(PG153), 4핀 | 확인(IP 존재), 구성은 설계안 |
| 통신 확인 | 0xD0을 읽어 0x60이 오는지 검사 | 확인(값) |
| 보정 | 소자별 보정 계수를 읽어 소프트웨어에서 계산 | 설계안 (계수 레지스터는 미기록) |

## 레지스터·보정 (확인: Bosch DS002, PDF 추출)
| 항목 | 값 |
|---|---|
| 보정 계수 | 0x88~0xA1 (T1..T3, P1..P9, H1 @0xA1), 0xE1~0xE7 (H2..H6). 16비트는 리틀엔디언, T1·P1 부호 없음 |
| H4 / H5 | H4 = 0xE4[11:4] + 0xE5 하위 니블[3:0], H5 = 0xE6[11:4] + 0xE5 상위 니블[3:0] |
| 제어 | 0xE0 reset(0xB6), 0xF2 ctrl_hum(osrs_h), 0xF3 status(bit3 measuring), 0xF4 ctrl_meas(osrs_t[7:5], osrs_p[4:2], mode[1:0]), 0xF5 config |
| 데이터 | 0xF7~0xFE: 압력 20비트, 온도 20비트, 습도 16비트. burst 읽기 권장 |
| 순서 | ctrl_hum 변경은 ctrl_meas 쓰기 후에 적용됨 |
| 출력 | 온도 0.01 °C, 압력 Q24.8 Pa, 습도 Q22.10 %RH |
| 날씨 모니터링 설정 | 강제 모드, T/P/H ×1, 필터 끔, 1회/분 |

드라이버: `sw/bme280.h/.c` (계산·파싱은 순수 함수, I/O 는 axi_iic 사용), 테스트 `tb/test_bme280.c`.

## 근거와 한계
- 보정식 원문은 PDF 에서 추출한 텍스트이고 습도 식의 괄호는 추출 중 복원된 것이라 원문 대조가 필요.
- 테스트의 온도·압력 기대값(25.08 °C, 약 100653.27 Pa)은 BMP280 데이터시트 예제를 기억에서 가져온 것이고, 압력은 3 LSB(0.01 Pa) 차이가 나서 허용 오차를 둠. 습도는 계수가 임의 값이라 범위·단조성·클램프만 검사. BME280 데이터시트의 예제 계수로 재검증 필요.
- I/O 계층(bme280_init/measure)은 컴파일만 확인, 실행 안 함. 측정 대기는 최대 50 ms 폴링(상한은 설계안).
