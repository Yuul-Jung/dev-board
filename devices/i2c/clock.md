# I2C 시계: DS3231 — D1
| 항목 | 값 |
|---|---|
| 주소 | 1101000 (0x68), 쓰기 D0h / 읽기 D1h |
| I2C | 400 kHz |
| 정확도 | ±2 ppm (0~+40 °C) |
| 전원 | VCC 2.3 / 3.3 typ / 5.5 V, VBAT 2.3 / 3.0 typ / 5.5 V |
| 레지스터 | 00h 초 ~ 06h 연 (BCD) · 07h~0Dh 알람 · 0Eh 제어 · 0Fh 상태 · 10h 에이징 · 11h~12h 온도 |
| 온도 | 10비트 코드, 분해능 0.25 °C |
| 핀 | 32kHz 출력(오픈 드레인, 외부 풀업), INT/SQW(active-low 인터럽트 또는 구형파) |

SoC: AXI IIC 400 kHz. 주소 0x68 이 MPU-6050(AD0 Low)과 같으므로 MPU-6050 을 0x69 로 설정(`README.md`). INT/SQW 는 GPIO 인터럽트 후보.
SPI 시계 DS3234 는 `../spi/clock.md`. 요일/날짜 레지스터 세부 비트와 12/24시간 비트 배치는 이번 발췌에서 확인하지 못했습니다 (미확인).
