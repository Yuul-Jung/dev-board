# DS1307 실시간 시계, 24xx256 I2C EEPROM

<!-- nav -->[저장소 홈](../../README.md) › [devices](../README.md) › [i2c](README.md)

드라이버: [`sw/rtc_eeprom.h`](sw/rtc_eeprom.h), [`sw/rtc_eeprom.c`](sw/rtc_eeprom.c). 시험: [`tb/test_rtc_eeprom.c`](tb/test_rtc_eeprom.c). 근거는 Maxim DS1307 데이터시트 사본 2종, Microchip 24xx256(DS21203) 사본(D1, 본문 요약을 읽음). 이 저장소에는 이미 [DS3231](clock.md)이 있으며, 3.3 V 시스템에는 그쪽이 맞습니다.

## DS1307 (확인)
| 항목 | 값 |
|---|---|
| 주소 | 0x68 (고정) |
| 전원 | **VCC 4.5~5.5 V**, VBAT 2.0~3.5 V. 입력 High 최소 2.2 V (최대 VCC+0.3 V), 절대 최대 7.0 V |
| SCL | **100 kHz 만** (400 kHz 미지원) |
| 레지스터 | 00 초(bit7 = CH), 01 분, 02 시, 03 요일(1~7), 04 일, 05 월, 06 년(00~99), 07 제어. 전부 BCD |
| 시(02h) | bit6 = 12/24 선택(1 = 12시간제), bit5 = AM/PM(12시간제, 1 = PM) 또는 20시 비트(24시간제), bit4 = 10시 |
| 제어(07h) | bit7 OUT, bit4 SQWE, bit1:0 RS = 00 1 Hz, 01 4.096 kHz, 10 8.192 kHz, 11 32.768 kHz |
| RAM | 56바이트, 08h~3Fh. 포인터 자동 증가, 3Fh 다음 00h |
| 읽기 | START 시점에 시각을 복사해 그 복사본을 읽음 → 7바이트를 한 번에 읽어야 안전 |
| 전원 투입 | 레지스터 내용 정의되지 않음. 초기 설정 시 CH=0 으로 발진 시작 |
| 수정 크리스털 | 32.768 kHz, 부하 12.5 pF |
- 요일 값(1~7)을 어떤 요일에 대응시킬지는 문서에 없어 사용자 정의로 둡니다.
- **Basys3 연결 주의(설계안)**: 3.3 V 로 구동하면 규격 밖이고, 5 V 로 구동하면 SDA/SCL 의 풀업과 FPGA 입력 보호가 필요합니다(FPGA 핀은 5 V 입력 불가). 레벨 변환기를 쓰거나 DS3231 을 쓰는 편이 안전합니다.

## 24xx256 EEPROM (확인)
| 항목 | 값 |
|---|---|
| 제어 바이트 | 1010 A2 A1 A0 R/W → 7비트 0x50~0x57 |
| 주소 | 15비트(32K×8), 상위 바이트 먼저 두 바이트 |
| 페이지 쓰기 | 64바이트 버퍼, 페이지 경계는 64의 배수. 경계를 넘으면 같은 페이지 처음으로 감겨 **앞 데이터를 덮어씀** |
| 쓰기 사이클 | 최대 5 ms. 그동안 ACK 하지 않음 → ACK 폴링으로 완료 확인 |
| 순차 읽기 | 마지막 바이트에서 NACK + STOP. 7FFF 다음 0000 으로 감김 |
| 전원·클럭 | 24LC256: 2.5~5.5 V, 400 kHz. 24AA256: 1.7~5.5 V. 24FC256: 1 MHz |
| WP | VCC 에 묶으면 전체 쓰기 금지. 쓰기는 ACK 되지만 실행되지 않음(읽기는 영향 없음) |
- 드라이버는 쓰기를 **페이지 경계로 쪼개** 보내고, 조각마다 주소 설정 쓰기로 ACK 폴링(최대 20회 × 1 ms, 상한은 설계안).
- 읽기는 255바이트 단위로 나눠 매번 주소를 다시 지정(`axi_iic_read` 길이 한도).
- 24C02 같은 1바이트 주소 부품은 지원하지 않음(미작성). WP 가 High 이면 쓰기가 조용히 무시되므로 쓴 뒤 다시 읽어 확인할 것(드라이버는 확인하지 않음).

## 시험과 한계
- I2C 층을 위 규칙의 모델로 바꿔 검사: DS1307 BCD·12시간제 변환(12 AM→0, 12 PM→12, 11 PM→23)·범위 거부·CH 분리·제어값·RAM 경계, EEPROM 페이지 감김 모델에 대해 경계 걸침 쓰기와 임의 쓰기 300회가 기준 메모리와 일치, 마지막 바이트·범위 밖 거부, 쓰기 사이클 NACK 폴링과 시간 초과. ASan/UBSan 통과. 페이지 분할·12시간제 변환·SQW 비트·CH 비트·폴링 주소 순서를 일부러 틀리게 한 사본은 모두 실패로 잡힘.
- 모델은 내가 읽은 문서대로 내가 만든 것입니다. 보드에서 실행하지 않았습니다. 윤년·월말 자동 보정은 장치 몫이라 시험하지 않았습니다.
