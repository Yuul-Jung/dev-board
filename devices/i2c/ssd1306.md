# SSD1306 OLED (I2C) 드라이버

<!-- nav -->[저장소 홈](../../README.md) › [devices](../README.md) › [i2c](README.md)

128×64 단색 OLED. 드라이버: [`sw/ssd1306.h`](sw/ssd1306.h), [`sw/ssd1306.c`](sw/ssd1306.c), 시험: [`tb/test_ssd1306.c`](tb/test_ssd1306.c). SPI 연결 정보는 [../spi/display.md](../spi/display.md).

## 근거 수준 — 데이터시트 원문은 열지 못했습니다
| 항목 | 값 | 근거 |
|---|---|---|
| 7비트 주소 | 0x3C (SA0=L), 0x3D (SA0=H) | 형제 칩 SH1106 데이터시트(D1)에서 확인, SSD1306 은 2차 자료(D3, nnarain)가 0x3C 사용 |
| 제어 바이트 | Co=bit7, D/C#=bit6. 명령 0x00, 데이터 0x40 (Co=0 이면 이후 바이트 전부 같은 종류) | SH1106 데이터시트(D1) 비트 위치 + nnarain(D3) 값 |
| 명령 코드 값 | 0x20 0x21 0x22 0x40 0x81 0x8D 0xA0/A1 0xA4 0xA6 0xA8 0xAE/AF 0xC0/C8 0xD3 0xD5 0xDA | Microchip ASF 헤더 (D3) |
| 인자: 멀티플렉스 0x3F, 차지 펌프 0x14, 클럭 0x80, 대비 0x7F, 오프셋 0 | | nnarain 글 (D3) |
| COM 핀(0xDA 인자) | 0x12 또는 0x02 | **미확인**. 호출자가 지정. nnarain 은 0x02 |
| 프리차지(0xD9), VCOMH(0xDB) | 쓰지 않음(기본값) | 미확인 |
| 최대 SCL 클럭, 모듈 승압 회로 | | 미확인 |

## 동작
- 초기화: 표시 끔 → 클럭 → 멀티플렉스 63 → 오프셋 0 → 시작줄 0 → 차지 펌프 → 수평 주소 모드 → 리맵 → COM 스캔 → COM 핀 → 대비 → 표시 켬. 트랜잭션은 명령 경계(7·7·6바이트)로 나눔.
- 프레임버퍼 1024 바이트(`fb[page*128+x]`, 비트0 = 페이지 맨 위). `oled_flush` 는 창 0..127 × 0..7 설정 후 페이지당 한 트랜잭션(제어 0x40 + 128바이트).
- 그리기: 점, 가로줄, 사각형, 3×5 숫자 글꼴(0-9 - . : 공백, 자체 제작 — 센서 값 표시용). 범위 밖은 무시.

## 시험 결과와 한계
- 가짜 `axi_iic_write` 로 전송 바이트열을 기록해 검사: 초기화 순서 20바이트, 창 설정, 페이지 8개×129바이트, 표시 켬, 점·사각형·글꼴 비트 배치, 범위 밖 안전, 오류 전파. ASan/UBSan 통과. 차지 펌프 값을 일부러 바꾼 사본은 실패로 잡힘.
- **이 시험은 "내가 쓴 순서가 내가 적은 순서와 같다"만 확인합니다.** 순서 자체가 맞는지는 데이터시트 원문(SSD1306 PDF)과 실제 화면이 필요합니다. 보드에서 실행해 보지 않았습니다.
- 화면이 비거나 줄이 섞이면: 차지 펌프(모듈에 승압 회로가 없으면 외부 전원 필요), COM 핀 값(0x02↔0x12), 주소(0x3C↔0x3D)를 순서대로 의심.
