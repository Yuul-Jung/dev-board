# PS/2 (키보드·마우스) 수신

AMD IP 없음(열람한 문서 범위) → 전용 RTL. 구분: 확인 / 계산 / 설계안 / 미확인. 시뮬레이터가 없어 **Verilog 는 실행하지 못했습니다**.

## 확인된 프로토콜 (Digilent Pmod PS2 문서, D3 수준의 2차 자료)
| 항목 | 값 |
|---|---|
| 프레임 | 11비트: 시작 0, 데이터 8비트 LSB 먼저, 홀수 패리티, 정지 1 |
| 데이터 유효 | 클럭 하강 에지 |
| 클럭 | Tck 30~50 µs, Tsu/Thld 5~25 µs (본문에는 "20~30 kHz" 표기도 있음) |
| 유휴 | 클럭·데이터 High, 장치는 오픈 컬렉터 |
| 억제 | 호스트가 클럭을 Low 로 잡으면 키보드는 보내지 않음 |
| 키보드 | 누름 = 스캔 코드, 뗌 = F0 + 코드, 확장 = E0 접두(뗌은 E0 F0) |
| 마우스 패킷 | 3 x 11비트. 상태 바이트: XS/YS 부호, XV/YV 오버플로, L/R 버튼 |

문서에 없음(미확인): 호스트->장치 송신 절차(100 µs 억제, request-to-send), 마우스 활성화 명령(F4)과 응답, 리셋/자체 시험 응답, 풀업 저항값, 마우스 패킷 바이트 순서, 스캔 코드 표, 패리티 공식(홀수라는 것 외). Basys3 의 PS/2 핀(B17/C17)은 이번에 보드 매뉴얼로 확인하지 않았습니다(미확인).

## 설계 (rtl/, 수신 전용)
| 파일 | 역할 |
|---|---|
| ps2_rx_engine.v | 2단 동기 + 안정 필터(8클럭, 설계안), 하강 에지 표본, 패리티·정지 검사, 비트 간 2000 µs 타임아웃(설계안) |
| ps2_axil_regs.v | AXI4-Lite 레지스터 + 16바이트 FIFO |
| ps2_axil_top.v | 배선만 |

레지스터: 0x00 DATA(읽으면 pop, [8]=valid) · 0x04 STATUS([0] empty [1] full [2] overflow [3] parity [4] frame [5] timeout, 오류는 1 쓰기로 지움) · 0x08 CTRL([0] irq_en, [1] 쓰면 FIFO 비움) · 0x0C COUNT.

송신(LED 설정, 마우스 활성화)은 위 미확인 때문에 만들지 않았고, 그래서 두 선을 입력 전용으로 뒀습니다. 송신을 붙이려면 오픈 드레인 출력(IOBUF)이 필요합니다.

## 검증 상태
- `tb/model_ps2_rx.py`: 엔진 알고리즘을 클럭 단위로 옮긴 파이썬 모델. 정상 프레임 3개, 패리티 오류, 정지 오류, 타임아웃을 확인(ALL PASS). **Verilog 코드 자체의 검증은 아님.**
- `tb/tb_ps2_rx_engine.v`: 같은 시나리오의 자체 검사 테스트벤치, 미실행.
- `tb/test_ps2_sw.c` + `sw/ps2.*`: 누름/뗌/확장 키 분리 (호스트 테스트 ALL PASS). 스캔 코드 -> 문자 변환은 표가 없어 미작성.
- AXI 레지스터와 FIFO 는 눈으로만 검토했습니다.
