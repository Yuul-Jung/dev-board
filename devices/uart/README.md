# UART 소자와 SoC 연결

구분: **확인** = 이번 작업에서 문서를 열어 확인, **설계안**, **미확인**. 소자: [modules.md](modules.md).

## AXI UART Lite (PG142)
기능 (Xilinx 위키, D3): 전이중, AXI4-Lite, 보레이트·데이터 비트(5~8)·패리티(홀/짝/없음) 설정 가능, 송수신 FIFO 각 16문자.
레지스터는 Zephyr 드라이버(`uart_xlnx_uartlite.c`)에서 확인 (D3):

| 오프셋 | 이름 | 비트 |
|---|---|---|
| 0x00 | RX FIFO | 수신 데이터 |
| 0x04 | TX FIFO | 송신 데이터 |
| 0x08 | STAT | 0 RX 유효 · 1 RX 가득 · 2 TX 빔 · 3 TX 가득 · 4 인터럽트 활성 · 5 오버런 · 6 프레임 오류 · 7 패리티 오류 |
| 0x0C | CTRL | 0 TX FIFO 리셋 · 1 RX FIFO 리셋 · 4 인터럽트 활성 |

보레이트: 위키는 "설정 가능"이라고만 하고 합성 시점인지 런타임인지 적지 않았습니다. Zephyr 드라이버는 보레이트를 쓰는 코드가 전혀 없어 **합성 시점에 고정될 가능성이 높음(추정)**. PG142 본문은 열지 못해 확정은 미확인입니다. 따라서 소자마다 보레이트가 다르면 인스턴스를 나누는 설계안을 유지합니다.

## 포트 계획 (설계안)
| 연결 | 보레이트 | 포맷 | 근거 |
|---|---|---|---|
| Basys3 USB-UART (TXD B18, RXD A18, RM 확인) | 임의 | - | 디버그 콘솔 |
| NEO-6M GPS | 9600 (기본) | 8N1 | modules.md |
| HC-05 | 38400 (기본) | 8N1 | modules.md, 2차 자료 |
| MAX485 | 용도별 | - | 최대 2.5 Mbps |
UART Lite 인스턴스 소자당 1개, Pmod 핀은 TX/RX 2선. 보레이트가 합성 시 고정이면 소자별 인스턴스가 필요합니다(미확인이라 인스턴스를 나누는 쪽이 안전).

## 전용 RTL 여부
UART Lite 가 있으므로 소자 접근은 IP. 전용 RTL 후보는 RS-485 방향 제어(DE/RE) 자동화뿐이며, GPIO 한 비트를 소프트웨어가 제어하면 충분하므로 이번에는 작성하지 않았습니다.
