- 근거 등급: **D1**(TowerPro SG90 Analog 제조사 제품 사양, Keyestudio KS0194·Seeed Grove Servo 공식 튜토리얼) + **D3**(국내 판매처); 실제 보유품의 정품 여부·신호 HIGH 임계값은 **미확인**

## 2. 펄스·각도 범위

| 항목 | 근거/판정 |
|---|---|
| 위치 제어 예시 | Keyestudio KS0194는 20 ms(50 Hz) 주기, 중앙 1.5 ms 및 500~2500 µs 범위를 설명 |
| 기본 교육 설정 | `PERIOD=20000 µs`, `MIN=1000 µs`, `MAX=2000 µs`, `WIDTH=1500 µs` — **설계상 보수적 시작값**이지 제조사가 모든 SG90에 보증한 기계적 끝점이 아님 |
| Arduino Servo 라이브러리 | [Servo API](https://github.com/arduino-libraries/Servo/blob/440b319ec11ea2664df8ce201c271c935de28a2d/docs/api.md)는 `attach(pin,min,max)`와 `writeMicroseconds()`를 제공. 기본 매핑 544~2400 µs는 SG90 고유 안전 범위가 아님 |
| 각도 변환 | `servo_set_angle()`의 0~180은 MIN~MAX로 선형 대응하는 **소프트웨어 명령값**. 실제 축 각도·방향·기구 간섭은 별도 교정 |
| 신호 HIGH | SG90 Analog 제조사 페이지에 Basys3의 **3.3 V HIGH 인식 보증 수치 없음** → 실제 모델 데이터시트/시험으로 확인할 때까지 미확인 |

## 3. Basys3 / MicroBlaze V 연결 안전 게이트

- **P0 전원 분리:** SG90 전원 VCC(빨강)는 적합한 **별도 4.8~5 V 서보 전원**에 연결한다. Basys3의 3.3 V GPIO·XADC·Pmod I/O 핀으로 모터 전류를 공급하지 않는다.
- **P0 접지:** 별도 서보 전원 GND와 Basys3 GND는 신호 기준을 공유하도록 연결한다. 모터 전원 노이즈·전원 용량·배선·역극성 보호를 확인한다.
- **P0 신호:** Basys3 `servo_pwm`은 3.3 V 논리 출력이며 **서보 입력의 3.3 V HIGH 인식은 미확인**이다. 인식 불량 시 적합한 버퍼/레벨 변환을 검토하되 5 V 신호가 FPGA GPIO로 역유입되지 않도록 한다.
- **P0 전류:** Keyestudio KS0194 공식 사양은 4.8 V에서 무부하 약 200 mA, 정지(stall) 최대 850 mA 수준을 명시한다. 이 수치는 **KS0194 기준**이며 TowerPro Analog 전체 공통 보증치가 아니다. 실제 기구부와 전원 여유를 확인한다.
- **모듈 핀맵:** 갈색 GND·빨강 VCC·주황 SIGNAL은 KS0194 기준이다. 3선 서보와 Grove 커넥터는 핀 배열이 동일하다고 가정하지 않는다.
- **다른 센서와 혼동 금지:** XADC 일반 단극성 입력 0~1 V, HC-SR04 5 V ECHO, I²C SDA/SCL 풀업 전원은 별도 P0 점검 대상이다. SG90 제어선에 I²C·XADC를 적용하지 않는다.

## 4. RTL / C 드라이버 / 검증 상태

- RTL: `rtl/servo_axil_top.v`(보드 연결용 래퍼) → `servo_axil_regs.v`(AXI4-Lite 레지스터) → `servo_engine.v`(펄스 생성)
- Register Map: CTRL 0x00 / WIDTH 0x04 / PERIOD 0x08 / MIN 0x0C / MAX 0x10 / APPLIED 0x14(읽기 전용), 폭·주기는 16비트 µs 단위.
- C: `sw/servo.[ch]`의 `servo_init()`은 `0 < MIN <= MAX < PERIOD <= 65535`를 확인한 뒤 enable을 켠다. 직접 AXI 레지스터 쓰기는 C 검증을 우회한다.
- (2026-11-03 추가) `servo_engine.v`는 직접 AXI 쓰기 등으로 `PERIOD=0`, `MIN=0`, `MIN>MAX`, `MAX>=PERIOD`가 되면 PWM 출력을 LOW로 강제하고 `APPLIED=0`으로 보고한다. 이는 **회로 내부 fail-safe 정책**이며 실제 서보의 안전한 정지·전원 차단을 보증하지 않는다. 유효 설정으로 복귀하면 카운터를 처음부터 시작한다.
- 테스트: `tb/test_servo.c`는 호스트 모의 레지스터 시험. `tb/tb_servo_engine.v`는 펄스 폭·상한 제한과 무효 설정 시 PWM LOW를 검사하는 지정 시나리오. `tb/tb_servo_axil_regs.v`는 AXI AW/W·WSTRB·B/R 백프레셔 지정 시나리오.
- **검증 단계:** 소스 작성/호스트 시험/지정 RTL 시뮬레이션과 AXI VIP 전수 검증·Vivado 합성·타이밍·실물 서보 전원/회전 시험은 각각 별도 단계로 기록한다.
