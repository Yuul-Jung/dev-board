# 남은 일 (데이터시트·시뮬레이션 확인 전)

<!-- nav -->[저장소 홈](../README.md) › [devices](README.md)
## 문서를 열어야 값을 확인할 수 있는 것
- SPI(W5500): UDP 수신 헤더의 W5500 에서의 바이트 순서와 `Sn_RX_RD` 전진량(형식 8바이트는 확인, 순서는 W5100 라이브러리 근거만, 전진량은 WIZnet 문서 안에서 상충), 부분 도착 시 `Sn_RX_RSR` 반영 시점, 소프트 리셋 후 대기 시간, MACRAW 의 `Sn_SR` 값(영문 사본 p.47 0x02 / p.51 0x42 상충), `w5500_send` 가 TIMEOUT 으로 끝난 뒤 TX 포인터 상태, `Sn_TX_RD`/`Sn_RX_WR` 읽기 전용 여부, 요약이 아닌 PDF 원문 대조(현재 웹 가져오기 요약 + NuttX)
- 이더넷 응용(DHCP·DNS·NTP·HTTP·JSON): RFC 1035·2131·2132·5905·8259 원문 대조(DNS 의 RA/RCODE 폭, NTP 비트 배치·스트라툼 0/LI 3 의 의미·시대 처리)와 RFC 9112 전체(요약이 앞 100000자만 읽었음) 대조, 실제 DNS/NTP/HTTP 서버와의 상호 동작, NTP 왕복 지연 보정, DHCP 에서 W5500 의 SIPR=0.0.0.0 송수신·브로드캐스트 플래그·BROADCAST 플래그 필요 여부(보드에서 확인), HTTPS, JSON 해석을 실제 날씨 API 응답으로 확인(형식 미확인), 본문이 RAM 에 안 들어갈 때를 위한 스트리밍 해석
- SPI(MAX7219): CLK 휴지 레벨, 표시 시험 레지스터 전원 투입 값, 자릿수 방향과 8×8 행·열 방향(모듈별), PDF 원문 대조(요약 경유, 두 번째 출처 없음)
- SPI: ILI9341 데이터시트 본문(타이밍·초기화·COLMOD/MADCTL — 막힘, PDF 필요), microSD 사양, SSD1306 SPI 타이밍·차지 펌프, nRF24L01+ NOACK 패킷의 TX_DS 시점·수신 모드 중 STATUS 쓰기(실제 칩 확인), MCP2515 필터·마스크·슬립·오류 처리·OSM(드라이버 미작성), MAX31855 SPI 모드, ADXL345 데이터시트 원문 대조(현재 AN-1077 기반: 쓰기 R/W 비트 값·BW_RATE·DATA_FORMAT 비트·3선 모드), PG153 SCK 비율 선택지(본문 상충)와 p.105 예제
- GPIO(AXI GPIO, PG144): 입력으로 설정된 비트에 DATA 를 쓰면 저장되는지, 리셋 직후 DATA/TRI 값(문서 안에서 상충), 인터럽트가 레벨인지 에지인지, PDF 원문 대조(요약 경유). AXI Timer 자유 실행 시계의 ARHT=1 재적재 동작(PG079 본문은 확인, 실제 IP 동작 미확인). LM35 정확도·음의 온도 구성, CdS 셀별 lux 환산 값
- GPIO: AXI Timer PWM 0 %/100 %·ARHT 필요 여부(PG079 에 없음), 타코 캡처 후 카운터 동작, 엔코더 위상·클릭당 카운트, TTP223 원문, 부저 사양, 서보 3.3 V 신호 레벨
- I2C(HD44780): 글자 ROM 표(A00/A02)와 ASCII 차이, 20×4 의 3·4 행 주소(모듈 관례를 가정), 5 V 모듈의 입력 하이 레벨 최소값, 3.3 V 구동 시 오실레이터 속도, PCF8574 백팩 핀 배치(모듈마다), 백팩 I2C 풀업 전원, PDF 원문 대조(요약 경유)
- I2C: SSD1306 데이터시트 원문 대조(현재 2차 자료 기반 드라이버 작성됨, COM 핀 0xDA 인자·최대 SCL 미확인), SHT3x 응답 바이트 배치, DS3231 비트 마스크, MPU-6050 온도 변환식, ADS1115(비교기·ALERT·고속 모드·일반 호출 리셋 미작성), PCF8574A 주소·MCP23017 인터럽트·BANK=1 지도(미작성), DS1307 레벨 변환 설계·EEPROM WP 핀 동작 시험·24C02 계열(1바이트 주소) 미작성, BME280 데이터시트 예제 계수로 재검증, 습도식 괄호 원문 대조
- UART: HC-05 KEY 핀/AT 모드 진입·AT 모드 보레이트, HC-06 제조사 데이터시트(펌웨어별 `AT+BAUD`/`AT+UART` 차이, 명령 간격, 응답 지연), HM-10 제조사 최신 데이터시트·V6xx/V7xx 펌웨어·응답 접두 불일치(`OK+Set:` 대 `OK+SetName:`)·I/O 레벨, 블루투스 응답 끝을 판단하는 무음 구간의 적정값, NEO-6M UBX 설정, GGA 필드 순서와 `$`·`*` 의 XOR 범위, ESP, LoRa
- CAN: RXNEMP 재세트 동작, 트랜시버 핀·종단, 24 MHz can_clk 생성(MMCM), 라이선스 포함 여부
- PS/2: 송신 절차, 마우스 F4/응답, Basys3 핀, 스캔 코드 표
- Ethernet: Pmod NIC100 최대 SPI 클럭, W5500 모듈 사양, MicroBlaze V 에서 emaclite 동작
- I2S: 12.288 MHz 를 MMCM 으로 정확히 만들 수 있는지, 마스터 코덱 소자
- 기타: 1-Wire DS2438 등, 책 29장의 ESP32-S3 BLE(HM-10 은 AT 명령 브리지만 다룸)
- **모듈 회로도(사용자 확정본)**: L298 모듈, HC-06, HM-10, I2C LCD 백팩의 확정 회로도를 받으면 `motor/l298.md` 모듈 표, `uart/modules.md`, `i2c/lcd1602.md` 를 그 회로도로 다시 대조(전원·레벨·핀 배치·풀업·점퍼). 지금 표는 일반 시판 보드 기준.
## 사용자 쪽 실행이 필요한 것
- Vivado 에서 모든 `tb/` Verilog 테스트벤치 실행(이 환경에는 시뮬레이터 없음), 합성·타이밍 확인
- 드라이버를 보드에서 실행(현재는 호스트 모의 테스트만)
각 항목은 제조사 문서를 열어 값을 확인한 뒤 해당 폴더에 추가.
