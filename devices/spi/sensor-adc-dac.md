# SPI 센서·ADC·DAC: MAX31855, ADXL345, MCP3008, MCP4921

## MAX31855 (K형 열전대 → 디지털) — D1
| 항목 | 값 |
|---|---|
| 해상도 | 열전대 14비트 0.25 °C, 냉접점 12비트 0.0625 °C |
| 전원 | 3.0~3.6 V |
| 최대 SCK | 5 MHz |
| 변환 시간 | 최소 70 ms, 전형 100 ms (전원 인가 후 200 ms) |
| 출력 32비트 | D31 부호 · D30~D18 열전대 온도(LSB 0.25 °C) · D17 예약(0) · D16 오류 · D15~D4 내부 온도(LSB 0.0625 °C) · D3 예약(0) · D2 SCV · D1 SCG · D0 OC |

계산: 열전대 온도 = D31~D18 14비트 부호 있는 값 × 0.25 °C (비트 필드 기준, 설계안 해석).
SPI 모드: 열어본 발췌에서 확인 못 함 (미확인). 읽기 전용이라 MOSI 불필요.
SoC: 센서 버스 + CS. 100 ms 주기보다 빠르게 읽어도 값이 갱신되지 않을 뿐이라 폴링 주기 ≥ 100 ms 로 설계.

## ADXL345 (3축 가속도) — D1
| 항목 | 값 |
|---|---|
| 전원 | 2.0~3.6 V |
| SPI | 3선/4선. DATA_FORMAT(0x31) D6 SPI 비트: 0=4선, 1=3선 |
| 최대 SCK | 5 MHz (부하 100 pF 이하) |
| 모드 | CPOL=1, CPHA=1 (모드 3) |
| DEVID 0x00 | 0xE5 (읽기 전용) — 연결 확인용 |
| POWER_CTL 0x2D | D3 Measure=1 이면 측정 모드 |
| BW_RATE 0x2C | 리셋 0x0A = 100 Hz |
| DATAX0~DATAZ1 | 0x32~0x37, 2의 보수, x0/y0/z0 가 하위 바이트 |
| 주소 바이트 | R/W 비트 다음 MB(다중 바이트) 비트 다음 A5~A0 — 비트 위치는 확인, R/W 의 읽기 값(1/0)은 미확인 |

SoC: 센서 버스 모드 3, 인터럽트 핀은 GPIO. 연결 테스트: DEVID 가 0xE5 인지 읽기.

## MCP3008 (10비트 8채널 ADC) — D1
| 항목 | 값 |
|---|---|
| 모드 | 0,0 / 1,1 |
| 전원 | 2.7~5.5 V |
| 최대 샘플 속도 | 5 V 200 ksps, 3.3 V 130 ksps, 2.7 V 75 ksps |
| 최대 SPI 클럭 | 5 V 3.6 MHz, 2.7 V 1.35 MHz |
| 명령 | CS Low 후 첫 클럭에서 DIN High = 시작 비트, 다음 SGL/DIFF, 다음 D2 D1 D0 (000~111 = CH0~CH7 단일 종단) |
| 출력 | 10클럭 동안 MSB 먼저. CS 를 Low 로 두고 클럭을 계속 주면 LSB 먼저로 재출력 |

설계안(3바이트 프레임): 송신 `{0x01, (1<<7)|(ch<<4), 0x00}`, 결과 = ((rx[1] & 0x03) << 8) | rx[2]. 시작 비트 뒤 널 비트 위치는 이번에 문서에서 다시 확인하지 못했으므로 실제 보드에서 확인 필요(미확인).
SoC: 센서 버스, SCK ≤ 1.35 MHz (비율 128 → 781.25 kHz at 100 MHz, 계산). XADC(Basys3 내장)와 용도가 겹치지만 XADC 는 JXADC 입력 범위가 제한(별도 확인 항목)이라 채널 수·범위 필요 시 MCP3008 사용.

## MCP4921 (12비트 DAC) — D1 일부
| 항목 | 값 |
|---|---|
| 해상도 | 12비트 |
| 전원 | 2.7~5.5 V 단일 |
| 출력 | 이득 선택 비트로 풀스케일 VREF 또는 2×VREF, VREF 외부 |
| 정착 시간 | 4.5 µs, DNL 0.75 LSB, 전형 동작 전류 175 µA |
| SPI 모드, 최대 SCK, 16비트 명령 형식(A/B, BUF, GA, SHDN, D11~D0), LDAC | 열어본 페이지에 없음 — 미확인 |

명령 형식을 확인하기 전에는 드라이버를 쓰지 않습니다. 정식 데이터시트 PDF(50쪽)가 필요합니다.
