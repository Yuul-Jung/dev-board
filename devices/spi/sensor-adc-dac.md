## MAX31855 (K형 열전대 → 디지털) — D1
| 항목 | 값 |
|---|---|
| 해상도 | 열전대 14비트 0.25 °C, 냉접점 12비트 0.0625 °C |
| 전원 | 3.0~3.6 V |
| 최대 SCK | 5 MHz |
| 변환 시간 | 최소 70 ms, 전형 100 ms (전원 인가 후 200 ms) |
| 출력 32비트 | D31 부호 · D30~D18 열전대 온도(LSB 0.25 °C) · D17 예약(0) · D16 오류 · D15~D4 내부 온도(LSB 0.0625 °C) · D3 예약(0) · D2 SCV · D1 SCG · D0 OC |

계산: 열전대 온도 = D31~D18 14비트 부호 있는 값 × 0.25 °C (비트 필드 기준, 설계안 해석).
SPI 모드: 열어본 발췌에서 확인 못 함 (미확인). 읽기 전용이라 MOSI 불필요.
SoC: 센서 버스 + CS. 100 ms 주기보다 빠르게 읽어도 값이 갱신되지 않을 뿐이라 폴링 주기 ≥ 100 ms 로 설계.

## ADXL345 (3축 가속도) — D1
| 항목 | 값 |
|---|---|
| 전원 | 2.0~3.6 V |
| SPI | 3선/4선. DATA_FORMAT(0x31) D6 SPI 비트: 0=4선, 1=3선 |
| 최대 SCK | 5 MHz (부하 100 pF 이하) |
| 모드 | CPOL=1, CPHA=1 (모드 3) |
| DEVID 0x00 | 0xE5 (읽기 전용) — 연결 확인용 |
| POWER_CTL 0x2D | D3 Measure=1 이면 측정 모드 |
| BW_RATE 0x2C | 리셋 0x0A = 100 Hz |
| DATAX0~DATAZ1 | 0x32~0x37, 2의 보수, x0/y0/z0 가 하위 바이트 |
| 주소 바이트 | R/W(bit7) | MB(bit6) | A5~A0. **읽기 = bit7 1**: AN-1077 의 데이터 읽기 명령 0xF2 = 0x80\|0x40\|0x32 (확인). 쓰기의 bit7 = 0 은 이 문서에 직접 값이 없는 설계안 |
| 초기화 예(AN-1077, 확인) | DATA_FORMAT 0x31 = 0x0B (±16 g, 13비트), POWER_CTL 0x2D = 0x08 (측정), INT_ENABLE 0x2E = 0x80; 전원 후 1.1 ms 대기; OFSX/Y/Z 0x1E~0x20 은 8비트 2의 보수 약 15.6 mg/LSB |
| 스케일 | 13비트 모드 약 3.9 mg/LSB (다른 범위·FULL_RES 별 값은 이 문서에 없음) |
| 다중 바이트 | 데이터 레지스터는 한 번에 6바이트(MB=1) 읽어야 값이 일관됨(AN-1077). 출력은 16비트 2의 보수, 하위 바이트 먼저 |

드라이버: [`sw/spi_sensors.c`](sw/spi_sensors.c) (`adxl345_*`). 근거는 데이터시트가 아니라 응용 노트 AN-1077 이므로 BW_RATE·개별 비트·3선 모드 비트는 원문 대조 필요.

SoC: 센서 버스 모드 3, 인터럽트 핀은 GPIO. 연결 테스트: DEVID 가 0xE5 인지 읽기.

## MCP3008 (10비트 8채널 ADC) — D1
| 항목 | 값 |
|---|---|
| 모드 | 0,0 / 1,1 |
| 전원 | 2.7~5.5 V |
| 최대 샘플 속도 | 5 V 200 ksps, 3.3 V 130 ksps, 2.7 V 75 ksps |
| 최대 SPI 클럭 | 5 V 3.6 MHz, 2.7 V 1.35 MHz |
| 명령 | CS Low 후 첫 클럭에서 DIN High = 시작 비트, 다음 SGL/DIFF, 다음 D2 D1 D0 (000~111 = CH0~CH7 단일 종단) |
| 출력 | 10클럭 동안 MSB 먼저. CS 를 Low 로 두고 클럭을 계속 주면 LSB 먼저로 재출력 |

3바이트 프레임(계산, 데이터시트 직렬 규칙에서 도출): 송신 `{0x01, (SGL<<7)|(ch<<4), 0x00}`, 결과 = ((rx[1] & 0x03) << 8) | rx[2].
- 근거(확인): 시작 비트는 CS Low 후 DIN 의 첫 1, 이어서 SGL/DIFF, D2 D1 D0, 샘플 마무리 클럭 1개, 널 비트(0), B9..B0. 변환은 17클럭. 데이터시트는 첫 바이트에 "시작 비트 앞의 0 일곱 개"를 둔다고 설명하고 MSB 가 "클럭 14의 하강 에지"에서 나온다고 적는다 — 시작 비트가 8번째 클럭이면 널 비트는 14번째, B9 는 15번째 클럭(바이트2 bit1), B8 이 바이트2 bit0, B7..B0 이 바이트3. 하강 에지에서 나온 값을 상승 에지에서 읽으므로 앞의 "하강 에지 14" 와 모순 없음.
- 차동 모드: SGL=0, D2D1D0 이 쌍·극성을 고름 (000 CH0+/CH1-, 001 CH0-/CH1+, 010 CH2+/CH3-, …). LSB = VREF/1024, VREF 0.25 V ~ VDD, 최소 유효 클럭 약 10 kHz. 변환마다 CS 를 High 로 올려야 함.
- 드라이버: [`sw/spi_sensors.c`](sw/spi_sensors.c) (`mcp3008_read`), 시험 [`tb/test_spi_sensors.c`](tb/test_spi_sensors.c). 실제 칩에서의 프레임 정렬은 보드에서 확인 필요.
SoC: 센서 버스, SCK ≤ 1.35 MHz (비율 128 → 781.25 kHz at 100 MHz, 계산). XADC(Basys3 내장)와 용도가 겹치지만 XADC 는 JXADC 입력 범위가 제한(별도 확인 항목)이라 채널 수·범위 필요 시 MCP3008 사용.

## MCP4921 (12비트 DAC) — D1 일부
| 항목 | 값 |
|---|---|
| 해상도 | 12비트 |
| 전원 | 2.7~5.5 V 단일 |
| 출력 | 이득 선택 비트로 풀스케일 VREF 또는 2×VREF, VREF 외부 |
| 정착 시간 | 4.5 µs, DNL 0.75 LSB, 전형 동작 전류 175 µA |
| SPI 모드, 최대 SCK, 16비트 명령 형식(A/B, BUF, GA, SHDN, D11~D0), LDAC | 열어본 페이지에 없음 — 미확인 |
