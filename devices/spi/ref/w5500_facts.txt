# W5500 사실표 — 드라이버 헤더(spi/sw/w5500.h)의 상수를 대조하는 근거.
# 출처 DS = WIZnet W5500 Datasheet Version 1.0.5 (NOV 2014). 이 환경에서는 PDF 를 직접 내려받지 못해 웹 가져오기(WebFetch)가 돌려준 본문 요약에서 옮겨 적음
#        (사본 2개: docs.wiznet.io 의 w5500_kor.pdf 와 pdf.direnc.net 의 wiznet-w5500-datasheet.pdf. 두 사본이 겹치는 항목은 서로 같았음). 쪽수는 요약이 말한 쪽수.
# 출처 NT = Apache NuttX drivers/net/w5500.c (D3, 독립 소스, 소스 코드에서 상수를 옮김). '-' 는 그 출처에 없음.
# 줄 형식(| 로 구분):  def|헤더 매크로 이름|DS 값|NT 값|쪽수·메모     → 헤더의 매크로가 DS 값과 같아야 하고, NT 값이 있으면 DS 와도 같아야 함
#                    val|설명|DS 값|NT 값|쪽수·메모          → 헤더에 매크로는 없고 두 출처가 같은지만 봄
#                    !로 시작하는 줄은 두 출처가 다른 것을 알고 기록한 것(실패로 세지 않음, 드라이버는 DS 쪽을 따름)
