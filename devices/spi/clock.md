# SPI 시계: DS3234

## DS3234 (RTC + TCXO) — D1
| 항목 | 값 | 구분 |
|---|---|---|
| 정확도 | ±2 ppm (0~+40 °C), ±3.5 ppm (-40~+85 °C) | 확인 |
| 전원 | VCC 2.0 / 3.3 typ / 5.5 V, VBAT 2.0 / 3.0 typ / 3.8 V | 확인 |
| SPI 모드 | 모드 1, 3 지원. SCLK 극성은 CS가 Low 될 때 SCLK 상태로 장치가 결정 | 확인 |
| 최대 SCLK | 4 MHz (2.7 V ≤ VCC ≤ 5.5 V), 2 MHz (2.0 V ≤ VCC < 2.7 V) | 확인 |
| 레지스터 주소 | 읽기/쓰기: 초 00h/80h, 제어 0Eh/8Eh, 제어·상태 0Fh/8Fh | 확인 |
| 메모리 | 배터리 백업 SRAM 256바이트 | 확인 |
| 출력 | 32.768 kHz 푸시풀, 핀 3 | 확인 |
| 시간 레지스터 BCD 형식, 분~연도 주소 | 열어본 발췌에서 확인 못 함 | 미확인 |

SoC (설계안): 센서 버스(SPI0, 모드 3, 781.25 kHz(비율 128) — 한계 4 MHz 이내) + CS 1개. INT/SQW 는 GPIO 인터럽트 입력 후보. 전원 3.3 V 로 구동하면 확인 범위 안.
개발 보드의 시계 소자 확인 방법: 초 레지스터(00h) 읽기를 두 번 간격을 두고 비교(설계안).

## 시계류 인터페이스 정리
| 소자 | 인터페이스 | 비고 |
|---|---|---|
| DS3234 | SPI | 이 문서 |
| DS1302 | 3선(CE, I/O, SCLK) | SPI 가 아님 — 전용 RTL 필요 (이번에 데이터시트 열지 않음, 미확인) |
| DS1307, DS3231 | I2C | AXI IIC 경로, [`../i2c/`](../i2c/README.md) 에서 다룸(DS3231 문서 [clock.md](../i2c/clock.md)) |
