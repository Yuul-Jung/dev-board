# 로터리 엔코더 (A/B 직교 + 푸시 스위치)
근거: ALPS 엔코더 문서(D3 수준, 도면은 텍스트로 못 읽음). 구분: 확인 / 설계안 / 미확인.

| 항목 | 값 | 구분 |
|---|---|---|
| 디텐트 / 펄스 | 30 / 15 (문서에 "per revolution" 명시 없음) | 확인(문구) |
| 채터 / 바운스 | 3 ms max / 2 ms max (R = 5 kΩ 조건) | 확인 |
| 정격 | 엔코더 10 mA 5 V DC, 푸시 스위치 0.5 A 16 V DC (최소 1 mA) | 확인 |
| A/B 위상, 시계 방향의 앞선 상 | 도면만 있어 텍스트에 없음 | 미확인 |
| 권장 디바운스 | 문서에 없음 | 미확인 |

경로: AMD IP 없음(열람 범위) → 전용 RTL `gpio/rtl/quad_*.v`. A/B/SW 세 입력에 2단 동기 + 안정 필터(기본 3000 µs = chatter 상한, 설계안)를 걸고 전이 표로 센다. 방향 규약(00→10→11→01→00 = +1)은 설계안이며 INVERT 비트로 뒤집는다. 두 비트가 동시에 바뀌는 전이는 err 로만 기록한다.
전압: 입력은 FPGA 3.3 V 입력에 직결(풀업은 모듈 또는 FPGA 내부 풀업, 설계안). 모듈(KY-040 류) 풀업 전압은 미확인 → 5 V 풀업이면 레벨 확인 필요.
필터 트레이드오프(계산): 필터 시간보다 짧은 간격의 에지는 놓친다. 3 ms 필터는 빠른 회전(상 간 간격 3 ms 미만)에서 카운트를 놓칠 수 있음.
