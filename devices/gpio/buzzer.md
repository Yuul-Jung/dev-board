# 부저 (액티브 / 패시브)
이번에 부저 데이터시트를 열지 못했다. 전기 사양(전압, 전류, 공진 주파수)은 모두 **미확인**.

구분의 일반 원칙(설계안): 액티브 부저는 DC 로 울리고, 패시브 부저는 주파수를 외부에서 만들어 줘야 한다. 어느 쪽인지는 실제 부품 사양서 확인 필요.
경로: 패시브는 AXI Timer PWM `buzzer_tone()`(50 % 듀티, `gpio/sw/axi_timer_pwm.c`; 주기·하이 시간 공식은 PG079 원문으로 확인, 레지스터 값은 호스트 테스트로 계산만 확인). 액티브는 GPIO 1개. FPGA 핀 전류로 직접 구동 가능한지는 부저 정격 확인 전까지 판단하지 않고, 트랜지스터 구동을 기본 가정(설계안).
