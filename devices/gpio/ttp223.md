# TTP223 정전식 터치 센서 (1채널)
근거: Components101 페이지(D3). 데이터시트 원문은 열지 못함(링크가 다른 부품명으로 표기됨 → 원문 확인 필요).

| 항목 | 값 |
|---|---|
| 전원 | 2.0~5.0 V (인터페이스 표기 2.2~5 V) |
| 응답 시간 | 저전력 모드 220 ms (고속 모드 값은 없음) |
| 전류 | 전형 1.5 µA, 저전력 모드 최대 3.0 µA |
| 출력 | 직접/토글 선택(TOG), 액티브 하이/로우(AHLB). 핀-모드 대응표는 이미지라 텍스트에 없음 |
| 감도 | 외부 커패시터 0~50 pF |
| 자동 보정 | 약 4.0 s 주기 재보정 |
| 부팅 안정화 시간, 최대 ON 시간, 출력 구동 전류·논리 레벨 | 미확인 |

경로: 디지털 입력 1개 → AXI GPIO(사용자 규칙상 AMD IP) 또는 기존 GPIO. 전용 RTL 불필요. 모듈 출력 레벨이 VCC 에 따르므로 5 V 로 구동하면 FPGA 입력 보호 필요, 3.3 V 로 구동하면 확인 범위(2.0~5.0 V) 안(계산). 220 ms 응답 때문에 폴링 주기 ≥ 수십 ms 로 충분(설계안).
