# 4선 PWM 팬 (Intel 4-Wire PWM Controlled Fans 규격)
근거: 규격 PDF(mikrocontroller.net 사본, D3~D1). 구분: 확인 / 설계안 / 미확인.

| 항목 | 값 | 구분 |
|---|---|---|
| PWM 입력 주파수 | 목표 25 kHz, 허용 21~28 kHz | 확인 |
| PWM 입력 논리 | VIL 최대 0.8 V, 로직 하이 값 없음, 최대 개방 전압 5.25 V, 단락 전류 5 mA | 확인 |
| 타코 | 회전당 2펄스, 오픈 컬렉터/드레인, 메인보드 쪽 12 V 풀업(최대 13.2 V) | 확인 |
| 전원 | 12 V ±1.2 V, 기동 피크 2.0 A 이하 | 확인 |
| 0 % 듀티 동작(정지/최저속), 핀 배치, 3.3 V 논리 호환, 타코 싱크 전류 | 규격 본문에 없음 | 미확인 |

경로:
- PWM 25 kHz: AXI Timer PWM(`gpio/sw/axi_timer_pwm.c`). PG079 v2.0 원문 확인: 타이머 0 = 주기, 타이머 1 = 하이 시간, 카운트다운이면 주기 = (TLR0+2)·T_clk, 하이 = (TLR1+2)·T_clk. 100 MHz → TLR0 = 3998, 50 % → TLR1 = 1998(계산).
- 타코 입력: 12 V 풀업이므로 **FPGA 에 직결 금지**, 오픈 컬렉터를 3.3 V 풀업 + 트랜지스터/레벨 시프트 뒤에서 입력(설계안). 펄스 주기 측정 → RPM = 60 / (주기 × 2) (계산). 전용 RTL 은 필요 없다: 별도 AXI Timer 인스턴스의 캡처 모드(PG079 확인, `capturetrig0` 입력, 극성은 IP 파라미터)로 연속 두 캡처 값의 차를 읽는다(`gpio/sw/axi_timer_tach.c`, 모의 테스트: 주기 1,500,000 클럭 → 2000 RPM). PWM 이 타이머 0·1 을 모두 쓰므로 PWM 과 캡처는 인스턴스를 나눈다(확인). 카운터가 캡처 후 0 으로 되돌아가지 않고 자유 주행한다는 가정은 설계안.
- 팬 전원은 FPGA 보드 밖의 12 V 별도 공급 필요(Basys3 에서 12 V 팬 구동 전원 여부는 확인하지 않음).
PWM 핀을 FPGA 3.3 V 로 구동할 때 VIH 가 규격에 없어 하이 레벨 인식은 팬별 확인 필요.

## PG079 확인 요약 (AXI Timer v2.0, 7 series 지원)
- PWM 조건: 두 타이머 모두 MDT=0, GENT=1, PWMA=1, GenerateOut active-high(기본). LOAD 는 ENT 와 함께 지움. ENALL 에 1 을 쓰면 ENALL·ENT0·ENT1 이 세트.
- 캡처: MDT=1, CAPT=1, 캡처 시 카운터 값이 TLR 로, TINT 세트(1 을 써서 지움). ARHT=1 이면 덮어씀, 0 이면 TLR 을 읽기 전 추가 캡처는 무시.
- 카운터 폭 8/16/32 파라미터. 폭이 32 미만이면 주기 상한이 줄어든다(25 kHz 는 100 MHz 에서 4000 클럭이라 16비트면 충분).
- PG079 에 없는 것: PWM 0 %/100 % 처리, PWM 에서 ARHT 요구 여부.
