# HC-SR501 PIR 모션 모듈
- 분류: 모션 · 인터페이스: GPIO 입력 1선 · 근거: D3 (판매처/교육용 사양 페이지 1건, 페이지 내 값이 서로 다른 항목 있음)

## 사양 (확인: 해당 페이지 기준)
| 항목 | 값 |
|---|---|
| 전원 | 4.5~20 V (같은 페이지에 5~20 V 표기도 있음) |
| 출력 | TTL High 3.3 V, Low 0 V |
| 트리거 모드 | 점퍼: L = 반복 트리거 없음, H = 반복 트리거 (기본 H) |
| 출력 유지 시간 | 약 0.3 s ~ 5 min (조절 설명에는 5~300 s) |
| 블록 시간 | 기본 2.5 s (0~수십 초 설정), 잠금 시간 0.2 s 표기 |
| 감지 거리·각도 | 최대 7 m, 가변저항으로 약 3 m까지. 각도는 <120°, 110°, <110° 로 불일치 |
| 워밍업 | 전원 후 약 1분, 이때 출력이 0~3회 펄스할 수 있음 |
| 전류 | 65 mA (동작), 대기 50 µA 미만 |
| 사용 온도 | -15~+70 °C |

## SoC 연결 (Basys3 + MicroBlaze V)
| 항목 | 내용 | 구분 |
|---|---|---|
| 핀 | 출력 1선 → GPIO 입력 1핀. 전원 5 V는 외부에서 공급, GND 공통 | 설계안 |
| 레벨 | 출력 High 3.3 V라 FPGA 3.3 V 입력에 직결 가능 | 확인(해당 페이지) |
| 구현 | AXI GPIO 입력 1비트 + 인터럽트(상승 에지). 2-FF 동기화는 IP 입력단이 아니므로 확인 필요 | 설계안, 미확인 |
| 워밍업 처리 | 전원 후 약 60 s 동안 출력 무시 (소프트웨어 타이머) | 설계안 |

## 근거와 한계
1차 제조사 데이터시트가 아니고 모듈 사양은 판매처마다 다를 수 있습니다. 감지 각도 값이 페이지 내에서 불일치합니다. AXI GPIO 의 입력 동기화 여부는 이번에 확인하지 않았습니다.
