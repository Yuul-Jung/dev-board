CAPSTONE-02 · 버튼 기반 SG90 위치 서보 제어

신규 자체 통합 설계안 · 미구현 — 기존 서보 엔진/AXI 지정 시험은 별도 검증 범위입니다. 버튼 통합 RTL, Vivado 합성, 실물 서보 구동은 수행하지 않았습니다.

1. 교육용 구성

입력

Basys3 버튼 2개
좌 / 우 위치 명령

Controller (제안)

동기화·디바운스·단발 펄스
명령 폭 100 µs 증감

출력

LED 상태
SG90 위치형 서보 신호

↓
순수 RTL 경로

버튼 Controller → 기존 servo_engine → PWM

SoC 확장 경로

MicroBlaze V → 기존 servo_axil_regs → servo_engine

두 경로는 대안입니다. 하나의 엔진을 동시에 구동하지 않으며, Top은 보드 핀과 모듈 연결만 담당합니다.

2. 제안 명령 규칙

입력명령
ResetPWM 비활성, 초기 폭 1500 µs
Enable20 ms 주기, 1500 µs 중심 명령
왼쪽 버튼 단발100 µs 감소, 하한 1000 µs
오른쪽 버튼 단발100 µs 증가, 상한 2000 µs
동시/길게 누름동시 입력은 무시, 길게 눌러도 1회만 처리

1000~2000 µs는 교육용 보수적 시작 범위이며 모든 SG90의 기계적 안전 범위를 보증하지 않습니다. LED는 명령 상태만 나타내며 실제 축 위치 피드백은 아닙니다.

3. 실제 전기 연결 게이트

SG90 전원은 별도 4.8~5 V 전원에서 공급하고 Basys3와 공통 GND를 사용합니다. 서보 전류를 FPGA GPIO에서 공급하지 않습니다. 3.3 V PWM HIGH 인식은 실제 제품에서 확인 전 미보증이며, 필요 시 적합한 버퍼·레벨 변환이 필요합니다. 위치형 SG90과 360° 연속 회전형을 혼동하지 않습니다.

4. 기존 구현 자료와 시험 근거

자료현재 상태
servo_engine.v펄스 생성 RTL 소스 존재
servo_axil_regs.vAXI AW/W 독립 수락·WSTRB 지정 시험 보고
servo.cC 소프트웨어 드라이버 소스 존재
적대적 검증 기록PR 브랜치 CI 지정 시험 성공 기록. 통합 캡스톤 검증 아님

6. 미완료 게이트

버튼 Controller/디바운스 통합 RTL 및 TB, 무효 레지스터 설정에 대한 하드웨어 안전 정책, AXI VIP, Vivado 합성·Timing, 3.3 V 신호 수용 및 실물 전원·전류 측정, MicroBlaze V 통합은 모두 미실시입니다.
