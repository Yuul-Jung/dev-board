CAPSTONE-05 — 터치·버튼 이중 입력 반응시간 측정기

Basys3의 버튼으로 시작하고, TTP223 터치 입력으로 자극 이후 반응시간을 측정하는 자체 설계형 캡스톤.

검증 상태: 교육용 설계서·독립 HTML 작성. 신규 RTL·TB·합성·보드 테스트 미실시. 원본 튜토리얼의 코드·사진은 복제하지 않음.

1. 입력 → 제어 → 출력

입력 A

Basys3 시작 버튼

입력 B

TTP223 터치 모듈 (3.3V 확인)

Controller

동기화 → FSM → 1ms 시간 계측

출력

LED 자극·상태, 반응시간·오류

2. FSM

상태제어 규칙
IDLE버튼 시작 대기
WAIT2초 준비 지연, 터치 시 부정 출발
MEASURELED ON, 최초 터치까지 1ms 계수
RESULT결과 유지, 재시작 대기
FAULT부정 출발 또는 5초 무응답, 재시작 대기

3. 인터페이스·예상 시험

신호의미
clk, reset, start_pulse, touch_sync100MHz 기준 클록·초기화·시작·터치
cue_led, status_led[3:0]자극 및 상태 표시
reaction_ms[15:0], result_valid최초 반응 결과·유효 레벨
false_start, timeout조기 입력·무응답 상태

예상 시험: Reset/무입력, WAIT 중 터치, WAIT→MEASURE 경계 터치, 자극 후 350ms 반응, 5000ms 타임아웃, 입력 유지·바운스, 결과 후 재시작.

4. 안전·구현 순서

실물 TTP223 출력 극성·전원·3.3V HIGH 확인 → 동기화/디바운스 → 1ms tick → 독립 Controller → self-checking TB → XDC/합성/Timing → 실물 시험 → MicroBlaze V + AXI GPIO 확장. FPGA 3.3V 입력에 5V 직접 연결 금지. 측정값에는 1ms 양자화·필터 지연 오차가 존재한다.
