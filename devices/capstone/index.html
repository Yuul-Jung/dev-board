1. 공개 원본 사례

Keyestudio KS5003/KS5004 ESP32 42-in-1 센서 키트 · Project 47: Intrusion Detection

제조사 튜토리얼 — 배선도·예제코드·실행 결과

원본에서는 PIR 감지 시 LED와 능동 부저를 0.2초 켬 / 0.2초 끔으로 반복하고, 미감지 시 끕니다. 사용 부품은 ESP32, 확장 보드, DIY PIR, LED 모듈, 능동 부저 등입니다. 원본 MicroPython 핀은 PIR GPIO15, LED GPIO22, 부저 GPIO4이며 Basys3 핀 번호가 아닙니다.

원본 커밋: 4adb6ce · 원본 저장소의 라이선스 메타데이터는 미지정, 루트 LICENSE 파일 확인되지 않음. 원본 이미지·코드 재배포 없이 링크만 제공합니다.

4. 제안 레지스터 맵 — 아직 구현되지 않음

Offset레지스터접근제안 의미
0x00CTRLRW[0] enable [1] arm [2] alarm_latch_enable
0x04STATUSRO[0] pir_motion [1] alarm [2] last_distance_valid [3] last_timeout [4] busy [5] armed
0x08DISTANCE_CMRO[9:0] 마지막 정상 거리, valid=0이면 사용 금지
0x0CEVENT_PENDINGRW1C[0] pir_rise [1] near_distance [2] echo_timeout
0x10THRESHOLD_CMRW[9:0] 경보 거리, 초기 제안 20 cm
0x14IRQ_ENABLERW[2:0] 이벤트별 인터럽트 허용

주소는 기존 IP의 실제 레지스터 주소가 아니라 32비트·4바이트 정렬 교육용 설계안입니다. EVENT_PENDING은 W1C(1을 쓰면 지움), 같은 클럭의 새 이벤트가 지움보다 우선합니다. AXI4-Lite 연결·주소 배정·C 드라이버는 아직 구현되지 않았습니다.

SoC 경로: A안은 기존 AMD AXI GPIO로 PIR/LED를 다루는 기초 실습, B안은 새 Controller·Register Bank를 표준 AXI4-Lite 슬레이브에 연결하는 확장 실습입니다. 기존 us_axil_top.v·us_axil_regs.v의 WSTRB 누락·AW/W 동시 수락 문제는 2026-11-03 수정되었고, 지정된 AXI4-Lite 레지스터 RTL 회귀시험이 통과했습니다. 이는 기존 초음파 IP만의 검증으로, 신규 보안 AXI 슬레이브·AXI VIP·Vivado 합성/Timing·실물 보드 통합을 검증한 것은 아닙니다.
