CAPSTONE-03 · 로터리 엔코더 LED 카운터

신규 자체 설계안 · 통합 미구현 — 기존 엔코더 RTL/AXI 파일은 존재하지만 이 캡스톤의 LED 통합·합성·실물 검증은 실시하지 않았습니다.

1. 입출력 구조

입력

KY-040 A/B/SW
기판별 전원·풀업 확인

기존 엔진

quad_engine
카운트·방향·버튼

신규 제어기

encoder_led_controller
설계안, 파일 없음

출력

Basys3 내장 LED[7:0]
카운트 하위 8비트

2. 순수 RTL / SoC 확장

순수 RTL: 엔코더 → 기존 quad_engine → 신규 LED Controller → 내장 LED. SoC 확장: 기존 quad_axil_regs를 MicroBlaze V에서 읽고 IRQ를 처리하도록 별도 통합합니다. 두 경로에서 엔진/clear를 중복 구동하지 않습니다.

3. 기존 AXI 레지스터

주소실제 의미
0x00 COUNT32비트 부호 카운트 읽기, 하위 바이트 쓰기 시 초기화
0x04 STATUS버튼·press·error·step·direction, 이벤트 W1C
0x08 CTRL방향 반전·IRQ 허용

4. 안전·출처

5 V 풀업 엔코더 출력을 Basys3 3.3 V GPIO에 직접 연결하지 않습니다. KY-040 기판 변형에 따라 실제 A/B/SW HIGH를 확인합니다.

Keyestudio KS0013 · Seeed Grove Encoder · Arduino Modulino Knob. 세 제품은 전원·프로토콜이 같지 않습니다. 원본 재배포 라이선스가 확인되지 않은 그림·코드는 복제하지 않았습니다.

5. 검증 상태

항목상태
기존 RTL/AXI 파일 존재소스 확인
엔코더 3.3 V 전기 측정미실시
신규 LED Controller/TB미구현
Vivado 합성·Timing·보드미실시
