# 08차시 — 조이스틱과 RGB LED

[Arduino 전체 목차](../../README.md) · [32차시 테크트리](../../ROADMAP.md)

## 개요
입력 신호를 읽고 출력 장치를 제어한다. 이전 차시와 비교하여 늘어난 입출력 기능을 확인한다.

## 준비
- 대상 보드: Arduino UNO R4 Minima 또는 WiFi. 사용 보드와 포트는 Arduino IDE에서 직접 선택한다.
- 아날로그 조이스틱·공통 캐소드 RGB LED·220Ω 저항 3개
- 부품·모듈 회로도를 확인하고 외부 전원과 GND를 연결한다. LED에는 전류 제한 저항을 넣는다.

## 배선
조이스틱 VCC→5V(모듈 사양 확인), GND→GND, VRx→A0, VRy→A1; 공통 캐소드 RGB 각 색 D3/D5/D6에서 220Ω 저항 거쳐 연결

## 전체 소스
[08_joystick_rgb.ino](08_joystick_rgb.ino)

소스 파일은 이 폴더에서 열어 그대로 업로드한다. (README와 .ino를 같은 디렉터리에 배치함)

## 실행 절차
1. Arduino IDE에서 보드와 USB 포트를 선택한다.
2. 스케치 파일을 열어 컴파일(검증)하고 업로드한다.
3. 입력값을 변화시키면서 출력의 변화를 관찰한다.

## 예상 결과
조이스틱 X/Y 위치에 따라 빨강/초록 밝기가 바뀌고 파랑은 중앙에서 밝다.

## 확인 및 주의
- 상태: **소스 작성 / 컴파일 미검증 / 실물 미검증**
- 실제 컴파일 성공 또는 보드 동작을 아직 주장하지 않는다.
- 조이스틱 모듈 VCC 정격과 RGB LED 극성을 실제 부품에 맞춰 확인한다.
